# 협력 출격

2026-10-26 기준 · v2 구현 · 결정 D-085

> **현재 설정(D-085, 2026-10-26)**: 기본 첫 충전·재충전 **40초**, 출격 **10초**, 궁극기 **2회(0.4·5.4초)**. 계정 연구 「협력 호출 최적화」 3단계는 별 **5·8·10개**로 단계마다 3초 단축하여 **37·34·31초**가 된다. 재충전은 호출 시점부터 계산하며, 전투 시작 시 연구 단계를 복사한다.

내가 보유한 다른 캐릭터 1명을 전투 중 잠시 호출해 스테이지 공략을 돕는 기능이다. 지원 캐릭터가 대표 필살기를 사용하고 짧게 공격한 뒤 철수하며, 캐릭터 특성에 따라 주인공과 시너지를 만든다.

## 1. 편성 조건과 선택 방식

- 목록에는 현재 10종과 이후 ROSTER에 추가된 캐릭터를 모두 표시한다. 별도 협력 정의가 없으면 기본 머리 기술 연출의 공통 지원 공격을 자동 제공한다.
- 해금된 캐릭터이며 머리·몸통·팔·다리 4부위의 보유 파츠를 갖춰야 한다.
- 현재 출전하는 주인공과 파견 중인 캐릭터는 지원에서 제외한다.
- 편성한 협력 캐릭터를 주인공으로 선택하면 협력 편성을 자동 해제하고 메인 버튼에서 재편성을 안내한다. 예전 중복 저장도 시작 시 정리한다(D-086).
- 메인 화면 **협력 출격** 또는 작전 지원의 **협력 출격** 탭에서 1명을 직접 선택한다. **지원 없음**도 가능하다.
- 메인 버튼은 편성한 캐릭터의 얼굴·이름·간략 효과를 보여주며 수동 Q 문구는 표시하지 않는다. 미선택이고 편성 후보가 있을 때만 은은한 강조로 선택을 유도한다. 선택 화면의 선택 카드는 밝은 테두리·배경과 **✓ 선택됨** 배지로 구분한다(D-087).
- **보유 캐릭터 중 랜덤 편성**은 조건을 만족하는 후보만 추첨한다. 결과를 출격 전에 공개하고 저장하며, 호출할 때마다 다시 추첨하지 않는다.
- 편성 후 주인공·장비·파견 상태가 바뀌면 출격 시 조건을 다시 검사한다. 부적격 지원은 투입되지 않으며 스테이지에는 출격할 수 있다.

직접 선택을 기본으로 두어 역할과 시너지를 계획할 수 있게 하고, 랜덤은 원하는 사람만 선택하는 편의 기능으로 제공한다.

## 2. 첫 충전과 반복 호출

| 항목 | 현재 규칙 |
|---|---|
| 최초 상태 | 게이지 0%. 전투 시작 직후 호출 불가 |
| 첫 호출 | 게임 시간 기본 40초 충전 후 가능 (연구 최대 31초) |
| 재호출 | 호출한 시점부터 게임 시간 기본 40초 재충전 (연구 최대 31초) |
| 출격 시간 | 게임 시간 10초·궁극기 2회. 출격 중에도 다음 충전 진행 |
| 저장량 | 최대 1회분. 오래 기다려도 추가 횟수는 쌓이지 않음 |
| 동시 출격 | 지원 본체 1명 |
| 비용 | 무료 |
| 조작 | **Q** 또는 전투 화면 좌측 상단 상태창 아래 지원 초상화 클릭 |
| 초기화 | 새 스테이지·재시작마다 빈 게이지로 시작 |

일시정지·히트스톱 중에는 충전과 출격 시간이 멈추며, 배속·슬로모션을 따른다. 연출 중에는 호출할 수 없다. 충전이 완료돼도 유효 대상이 없으면 호출을 보류하고 게이지를 보존한다. 봉합 성녀는 부상한 주인공·아군을 보호하기 위해 적이 없는 상황에서도 호출할 수 있다.

## 3. 전투 화면과 효과 안내

- 협력 UI는 **좌측 상단 주인공 상태창 바로 아래**에 가로형 카드로 묶는다. 주인공이 있는 하단 전장을 비우고 체력·지원 상태를 함께 확인할 수 있게 한다(D-072).
- 기존 스킬과 같은 **팔각형 초상화 버튼**을 사용한다. 초상화 위의 어두운 부채꼴이 줄어들며 충전 진행을 보여주고, 가운데 숫자로 남은 초를 표시한다. 초상화는 64px로 줄여 카드 높이를 최소화한다.
- 충전 중에는 버튼을 비활성화한다. 준비가 끝나고 대상이 있으면 캐릭터 색 테두리와 준비 효과로 호출 가능 상태를 알린다.
- 평소에는 **초상화·캐릭터 이름·충전/지원 상태·간략 효과 한 줄·지원 자동 ON/OFF**를 표시한다(D-073). 이름 옆 상태는 `첫 충전 / 재충전 / 호출 가능 / 대상 대기 / 지원 중`으로 간소화하고, 남은 초는 초상화 버튼 안에서만 표시한다. 효과는 `적 조종 · 방어 25% 무시`처럼 짧게 안내한다.
- **효과 상세 ⓘ**를 누르면 같은 상단 자리에서 카드 대신 효과 요약·대표 필살기·전체 효과·시너지·보스/거점 예외·충전 규칙을 펼쳐 볼 수 있다. 충전 중에도 설명을 열 수 있으며 설명 열기는 호출을 소비하지 않는다.
- 상세는 높이를 230px 이내로 제한하고 긴 내용은 내부 스크롤로 확인한다. 주인공·거점/보스 체력바와 겹치지 않도록 상단 왼쪽 범위 안에 둔다.
- 상세가 열리면 가려진 카드 조작은 숨기고 닫기에 포커스를 옮긴다. **닫기 버튼·바깥 클릭·Escape**로 닫는다. 닫기/Escape 후에는 상세 버튼으로 포커스를 돌려주며 기존 일시정지 단축키도 유지한다. 설명을 보는 동안에도 전투는 계속된다.
- **지원 자동 ON/OFF**는 일반 스킬 AUTO와 별개이며 저장된다.

## 4. 10초 출격 흐름과 근접 배치

일반 공격의 발사·타격·투사체 크기를 1.5배로 키워 작은 화면에서도 잘 보이게 한다(D-086). 피해량·주기·투사체 속도와 도착 시간은 유지한다.

| 시점 | 동작 |
|---|---|
| 0~0.4초 | 등장 |
| 0.4초 | 첫 번째 대표 필살기 발동 |
| 1.9~5.4초 | 사거리 안의 적에게 기본 공격 |
| 5.4초 | 두 번째 대표 필살기 발동 |
| 6.9~9.5초 | 기본 공격 재개 |
| 9.5~10초 | 철수 |

근접 캐릭터가 이동만 하다 사라지는 문제는 **소환 위치**로 해결한다. 장착 팔의 공격 방식이 근접이면 가까운 적의 아군 쪽 공격 사거리 안에 즉시 등장하고, 원거리 장비면 주인공 주변에 등장한다. 살아 있는 거점·바리케이드 너머로 배치하지 않는다.

첫 대상이 죽으면 가까운 다음 적에게 출격당 한 번, 최대 260px를 0.22초 동안 돌진한다. 등장 중 목표가 먼저 죽은 경우도 포함한다. 돌진 중에는 기본 공격을 하지 않고, 총 출격 시간은 늘리지 않는다. 따라서 필살기 사용 후 기본 공격도 유지한다.

지원 본체는 무적이며 적의 공격 대상이 되지 않는다. 지원이 만든 임시 소환수는 기존 아군처럼 공격하고 피해를 받는다. 지원 등장 연출은 전투를 멈추지 않으며 주인공의 필살기와 함께 사용할 수 있다.

협력 제어 효과가 적용된 적을 둘러싸던 네모 테두리는 제거한다(D-076). 기존 스킬 이펙트와 기절·구속·빙결·조종 판정은 유지한다. 추가 아이콘·오라는 이번에 넣지 않으며, 발동·지속 상태의 시각 표현은 스킬 목록을 정리한 뒤 각 스킬 기준으로 검토한다.

## 5. 캐릭터별 역할과 시너지

피해 증가·약화 표식·보호막 등 지원 효과는 출격 중에만 유효하다. 추천 연계는 편성 안내이며 조합 제한이 아니다. 다른 캐릭터도 해당 공격 조건을 만족하면 시너지를 받는다.

| 지원 캐릭터 | 대표 필살기와 핵심 효과 | 시너지 / 보스·거점 대응 | 추천 연계 |
|---|---|---|---|
| 거대로봇 | **스웜 드론 총출격**: 드론 6기로 포격 | 명중한 적에게 주인공 원거리 피해 +15% | 히어로·무희·길잡이 |
| 거대괴수 | **대지 포효**: 광역 피해, 일반 적 2초 기절 | 표식 적에게 주인공 근접 피해 +15%. 보스·거점에는 기절 없이 피해 | 합성괴인·인형사 |
| 타락 히어로 | **대세뇌**: 일반 적 최대 2기 임시 아군화 | 표식 주변 적 공격 피해 -15%. 보스·거점은 세뇌 대신 약화 | 로봇·무희 |
| 합성괴인 | **파괴 광란**: 광역 강타와 연속 공격 | 주인공·기존 소환수 공격속도 +15% | 괴수·성녀·인형사 |
| 심연의 길잡이 | **심연의 손**: 일반 적 2초 구속, 지속 피해 | 표식 적에게 주인공 범위 피해 +15%. 보스·거점은 구속 대신 피해 표식 | 로봇·괴수 |
| 봉합 성녀 | **억지 부활**: 시체 우선, 일반 적까지 최대 3기 임시 아군화 | 주인공·기존 소환수 보호막 8%, 보스 상황 12%. 지원 육성량에 따른 상한 적용 | 합성괴인·인형사 |
| 서리의 무희 | **영원한 안식**: 일반 적 1.5초 빙결 후 파쇄 | 대상당 주인공 첫 타격에 추가 파쇄 1회. 보스·거점은 빙결 대신 추가 피해 표식 | 괴수·합성괴인 |
| 뒤틀린 인형사 | **인형 실**: 일반 적 최대 4기를 3초 조종 | 표식 적에게 주인공 공격이 방어 25% 무시. 보스·거점은 조종 대신 방어 약화 | 로봇·히어로 |
| 철거의 설계자 | **철거 명령**: 크레인 철구 3연타 | 지원 궁극기의 거점 피해 3배 | — |
| 침묵의 방송자 | **긴급 방송**: 음파 폭발 3연타 | 일반 적 4초·보스 2초 침묵, 거점에는 피해만 | — |

대표 필살기는 현재 지원 전용 10종이며, 장착 머리의 필살기와 다를 수 있다. 능력치·강화·등급·장비 옵션·장착 머리 스킬 레벨은 스테이지 출격 시 복사해 고정한다. 주인공의 장비나 흡혈 효과를 빌리지 않는다.

연구 「협력 호출 최적화」는 3단계로 별 5·8·10개(총 23개)를 사용한다. 첫 충전·재충전을 단계마다 3초씩 줄여 37·34·31초가 된다.

## 6. 자동 호출과 추가 검토사항 반영

| 검토 항목 | 반영 방식 |
|---|---|
| 자동 호출 | 첫 충전/재충전 완료 후 보스·엘리트 밀집·적 4명 이상·주인공 체력 40% 이하·최종 거점·시간 부족 등을 보고 판단. 성녀는 생존/보스/최종 공략 우선 |
| 보스 무력화 방지 | 세뇌·빙결·구속·조종 대신 피해·약화·추가 피해 표식으로 대체 |
| 육성 가치와 과도한 성장 방지 | 지원 자신의 장비를 반영하되 보호막·추가 파쇄에 상한 적용 |
| 보상 중복 방지 | 세뇌·생체 전환에 처치/드랍 보상을 지급하지 않음. 실제 공격 처치는 기존 보상 경로에서 한 번만 처리 |
| 재호출 간 효과 누출 방지 | 매 호출에 별도 소유 번호를 부여하고 이전 출격의 예약 공격이 다음 출격에 영향을 주지 않도록 분리 |
| 철수·승패·퇴각·재시작 | 지원 표식·임시 소환수·드론·보호막·예약 작업 정리. 주인공의 기존 소환수·버프·보호막은 보존 |
| 계측 | 전투 전체의 지원 호출 수·직접 피해 누적, 재시작 시 초기화 |
| 가독성 | 상단 상태창 아래 최소 정보와 효과 한 줄, 남은 초는 버튼에만 표시, 전체 설명은 상세에서 확인, 상세도 주인공·기존 HUD를 가리지 않도록 높이 제한 |

## 7. 후속 조정

- 스킬 목록이 정리되면 주인공·협력을 포함해 각 스킬의 발동/지속 효과 표현을 함께 정리한다. 협력 호출 자체를 기준으로 별도 상태 연출을 추가하지 않는다(D-076).

- 첫 충전·재충전 기본 40초(연구 최대 31초)에서 실제 호출 횟수와 사용 기회를 플레이 기록으로 평가한다.
- 전체 캐릭터 조합·장비·난이도의 체감 밸런스와 실제 휴대폰 성능을 측정한다.
- 장착 머리별 모든 필살기 지원, 친구 캐릭터 대여, 여러 지원 슬롯은 현재 범위에 포함하지 않는다. 필요하면 별도 결정 후 확장한다.
