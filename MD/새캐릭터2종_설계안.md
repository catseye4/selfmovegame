> **상태**: 1차 안 — 그림·코드·이펙트 시트 완료 (2026-10-23, D-079). 사용자 "설계자와 방송자 캐릭터 작업부터 해줘. 기존 캐릭터들과 동일하게 등급별 파츠 작업과 스킬 이펙트 작업도 같이 해줘" — 배경·적 그림(구역 6)은 나중.
> 이야기·외형 기준: [새캐릭터_컨셉_재조정.md](새캐릭터_컨셉_재조정.md) 1장 5)·6) 원문, 컨셉 시트 [캐릭터 컨셉 4차.png](캐릭터%20컨셉%204차.png) (참고 그림 `MD/concept_refs/9_철거의설계자_*`, `10_침묵의방송자_*`).

## 2. 기본 스킬 (기본·강화 파츠가 같은 스킬 — 강화는 능력치와 그림)

| | 철거의 설계자 | 침묵의 방송자 |
|---|---|---|
| 기본 공격 | **공압 드릴** — 근접 3연타 + 옆 적 휩쓸기 | **공명 음파** — 분홍 음파가 앞 적 셋을 꿰뚫음 |
| 팔 스킬 1 (9초) | **기초 파쇄** — 드릴을 땅에 박아 앞쪽 지면이 터짐: 범위 피해 + 1초 기절, 거점·바리케이드 2배 (컨셉 "기초 파쇄") | **공명 파열** — 소리굽쇠를 울려 음파 고리 3겹이 앞으로: 지나간 적 피해 + 0.8초 기절 (컨셉 "공명 파열") |
| 몸통 스킬 2 (14~15초) | **강제 재건** — 앞에 철골 바리케이드 6초: 보스가 아닌 적은 넘어오지 못함, 끝날 때 무너지며 피해 (컨셉 "강제 재건") | **정적의 장막** — 앞에 반구형 분홍 장막 6초: 안의 적 **침묵**(원거리·치유·기술 못 씀) + 투사체 막음 (컨셉 "정적의 장막") |
| 머리 필살기 | **철거 명령** — 크레인 철구가 앞쪽을 세 번 내리침: 큰 피해, 거점 3배 | **긴급 방송** — 도시 스피커를 장악: 화면 적 4초 침묵 + 음파 폭발 3번 |
| 다리 패시브 | **안전화**: 거점·바리케이드 피해 +25% (강화 +35%) | **잡음 차단**: 침묵한 적에게 주는 피해 +20% (강화 +30%) |

- **침묵** (새 상태, 아이콘 `mute`): 적이 원거리 공격·치유·바리케이드 세우기·특수 공격(감전·도끼·방패 강타 등)·보스 기술을 못 씀 — 근접으로 때리는 것만. 거점·바리케이드에는 안 걸림.
- **철골 바리케이드** (그림 있는 장판): 강철 벽 장판(`wall`, 거대로봇 D-071)에 그림을 얹음 — 걸을 때 바닥과 함께 흘러감.

| 머리 | 주황 안전모·고글 → 작업등 강화 안전모 | 흰 헤드폰·안테나 → 분홍 바이저 방송 헤드셋 |

## 4. 세트 9개씩 (1차 안)

규칙은 2차 기획안 2장 그대로: 레어 ①~④(DM 구매·하드 드랍), 유니크 ①~③(헬 드랍·조각), 레전더리 ①②(나이트메어 드랍·조각). 유니크 ①·레전더리는 새 기본 공격.
칸의 (숫자)는 쿨다운(초). **시트** = Gemini 대표 이펙트 시트 (받기 전에는 기존 시트를 색 돌려 임시).
