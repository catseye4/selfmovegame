> **상태**: 기획 (2026-10-10). 방향은 사용자 결정 **D-050**, 이름·수치·스킬은 이 문서의 1차 안 — 만든 뒤 `balance_sim.py`로 측정해 고친다.
> **7장 캐릭터 선택창 + 연구소 수정은 먼저 만듦** (2026-10-14, 사용자 요청, D-051). 파츠 확장(1~6장)은 아직.
> **목표**: 기존 4종에 **부위마다 새 파츠 2개씩** (캐릭터마다 8개, 모두 32개). 새 파츠마다 **그림·스킬(패시브)·이펙트를 새로**. 그다음 **캐릭터 선택창 + 연구소는 고른 캐릭터 파츠만** (7장).
> 작업 브랜치: `feature/rig-characters-vfx` (원래 v2 브랜치, 사용자 결정). 새 캐릭터 4종은 `feature/new-characters`.

## 3. 새 파츠 원칙

- **가격**: 세트마다 머리 750 · 몸통 800 · 팔 900 · 다리 750 = **3200 DM**. A·B는 같은 가격대 — 위아래가 아니라 **노는 방식이 다른 선택지**.
- **능력치**: 세트 합이 기본보다 체력·피해 +15~30% 안. 세트 성격에 맞게 치우침(탱커는 체력, 원거리는 사거리). 지금 문제(괴수 느림, 히어로·레이저 강함)를 같이 고침.
- **스킬·패시브는 모두 새것**, 기존 4종·새 캐릭터 4종과 겹치지 않게. 겹칠 때는 "다르게 하는 점"을 적음.
- **기본 공격이 바뀌는 팔**: 공격 방식(`attackType`)이 새로 생기는 팔은 표에 표시 — 이펙트·판정을 새로 만듦.
- 이름·모습은 컨셉 시트([캐릭터 컨셉.png](캐릭터%20컨셉.png))의 색과 결을 그대로.

## 6. 기술 메모 — 원래 v2 브랜치에서 할 때

- **부위 그림 바꿔 끼우기**는 `feature/new-characters`에만 있음(`rigAvatar.applyUpgrades`·`setUpgrades`, `rig.js` `socketAlias`, 파츠 `rigUpgrade`, 연구소 카드 그림, 테스트 화면 버튼). 여기서는 그림이 **세 벌**(기본·A·B)이라 일반화해서 가져옴: 파츠에 `rigVariant: 'a' | 'b'` → 그 부위 뼈의 그림을 `<부위>_a` / `<부위>_b`로, 소켓도 바꿈. 새 캐릭터의 `rigUpgrade`는 `rigVariant: 'up'`과 같은 뜻이 되게 맞춰 두면 두 브랜치를 합칠 때 쉬움.
- **자르기 스크립트 4개**에 세트 그림도 같은 선으로 잘라 `<부위>_a.png`·`<부위>_b.png`를 만드는 기능을 더함.
- **패시브 판정**: 지금은 파츠 id를 직접 비교(9곳). 새 패시브 8개는 `skills_v2.js`의 패시브 표 + 전투 코드 한곳(`battle/passives.js` 같은 새 파일)에서 처리.
- **스킬 32개**: 지금처럼 `SKILLS`에 정의, 효과는 캐릭터별 전투 파일(`battle/mechSets.js` 등)로 나눠 `battle_v2.js`가 메서드로 붙임. 수치는 `tuning.js`.
- **이펙트**: `vfx/<캐릭터>Vfx.js`에 추가. 새 그리기(낙하 검·분신·사슬·포탑 등)는 `vfxPlayer.js`.
- **효과음**: 새 캐릭터처럼 코드로 합성(`build_audio.py`), 필요하면 CC0 팩.
- **파츠 데이터**: `parts.js`는 구버전 공용이라 그대로 → 32개는 `partsExtra_v2.js`의 `V2_PARTS`.
- **검사·측정**: 캐릭터마다 `test_<캐릭터>_sets.py`, `balance_sim.py`에 `<캐릭터>_a`·`<캐릭터>_b`.
