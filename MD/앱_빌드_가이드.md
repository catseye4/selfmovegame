# Android 앱 빌드 가이드 (WebView · Capacitor, D-073 · 버전·업데이트 D-074 · NAS 업데이트 D-081)

게임(v2)을 Android 앱으로 감싼 것. 앱 안의 WebView가 게임 파일을 그대로 띄우므로, **게임 코드를 고치면 다시 모아서(sync) 빌드만 하면 된다.** 게임 파일은 모두 앱 안에 있다(글꼴 3종만 Google Fonts에서 받음 — 인터넷이 없으면 기본 글꼴로 보임). 새 버전은 **Synology NAS**에 올리면(`release.py`) 앱이 켤 때 알아채고 앱 안에서 받아 설치한다(5장, NAS 준비는 6장 — NAS 주소 없이 빌드한 앱은 GitHub 릴리스를 봄).

## 1. 구성

| 경로 | 내용 |
|---|---|
| `app/package.json` | Capacitor 7 (`@capacitor/core`·`cli`·`android`), 스크립트 `www`·`sync`·`apk` |
| `app/capacitor.config.json` | 앱 id `com.madoverlord.game`, 이름 "매드 오버로드", 게임 파일 폴더 `www` |
| `app/build_www.py` | 저장소의 `index.html`·`index.css`·`ui_v2.css`·`js/`·`assets/`를 `app/www/`로 복사. 게임이 읽지 않는 원본 그림(`src/`·`png/` 폴더, `*_raw.png`·`*_gemini.png`, 약 450MB)은 뺌 → 약 100MB. `index.html`에 두 줄을 넣어 **모드 선택 화면 없이 v2로 바로** 들어감 |
| `app/android/` | Android 프로젝트 (Capacitor가 만듦). 고친 곳: `MainActivity.java`(가로 전체 화면·상태/내비 막대 숨김·화면 꺼짐 막기·소리 자동 재생), `AndroidManifest.xml`(`sensorLandscape` 가로 고정), 아이콘(`mipmap-*`, 거대로봇 돔 그림)·시작 화면(`drawable*/splash.png`) |
| 올리지 않는 것 | `app/node_modules/`, `app/www/`, `app/android/app/src/main/assets/public/`(www 복사본), 빌드 결과물·`local.properties` (각 `.gitignore`) |

| `app/release.py` | 출시용 APK 만들기 → `app/dist/MadOverlord-<버전>-b<빌드>.apk` → NAS에 올리고 버전 기록 (5장) |
| `app/update.local.json` | NAS 주소(`feed`)·폴더(`nas_dir`) — **저장소에 올리지 않음**, 틀 `app/update.example.json` (6장) |
| `app/android/…/AppUpdatePlugin.java` | 앱 업데이트: 업데이트 정보 읽기(`fetchText`), APK 내려받기(진행률) → Android 설치 화면. "알 수 없는 앱 설치" 권한이 없으면 그 설정 화면을 엶 |

게임 쪽: `js/main_v2.js` 화면 맞춤 최소 배율 0.5 → 0.35 (휴대폰 가로 화면에도 다 들어가게), 설정·작전 지원·로딩 창도 같은 배율로 줄임(`ui_v2.css` — 예전엔 휴대폰에서 설정 창이 위아래로 잘림), 버전 `js/version_v2.js`, 업데이트 확인 `js/ui_v2/appUpdate_v2.js`(앱에서만, 웹은 버전만 표시).

## 2. 처음 한 번

- **필요**: Node.js(npm), Python 3, Android Studio(SDK 35 이상 + 내장 JDK 21). Capacitor 7은 JDK 21이 필요하다 — Android Studio에 들어 있는 `jbr`을 쓰면 된다.
- `app` 폴더에서 `npm install`
- `app/android/local.properties`에 SDK 경로 한 줄 (없으면 Android Studio가 만들어 줌): `sdk.dir=C:/Users/<이름>/AppData/Local/Android/Sdk`

## 3. 빌드

```bat
cd app
npm run sync                         :: 게임 파일 모으기(build_www.py) + Android 프로젝트에 복사
set JAVA_HOME=C:\Program Files\Android\Android Studio\jbr
cd android
gradlew.bat assembleDebug            :: → app\android\app\build\outputs\apk\debug\app-debug.apk
```

- Android Studio로 하려면: `npx cap open android` → ▶ Run (휴대폰을 USB로 연결하거나 에뮬레이터).
- 휴대폰에 바로 설치: `adb install -r app\android\app\build\outputs\apk\debug\app-debug.apk` (휴대폰 "개발자 옵션 → USB 디버깅" 켜기). APK 파일을 휴대폰에 옮겨 직접 설치해도 됨(출처를 알 수 없는 앱 허용).
- 첫 빌드는 Gradle과 Android 라이브러리를 받느라 몇 분 걸린다. 그다음부터는 1분 안팎.

## 4. 앱에서 확인한 것 / 알아 둘 것

- **에뮬레이터 시험** (2026-10-22): 앱 시험용 `MadOverlord_Test`(Medium Phone과 같은 Android 36.1 이미지, 저장 8GB, 가로)를 만들어 둠 — 기존 에뮬레이터는 저장 공간이 모자라 설치가 막힘.
  `emulator -avd MadOverlord_Test -no-window -no-audio` → `adb install -r …apk` → `adb shell am start -n com.madoverlord.game/.MainActivity` → `adb shell screencap -p /sdcard/a.png` → `adb pull`.
  콘솔 오류는 `adb logcat | findstr Capacitor/Console`. 창 없이 돌리면 그래픽 카드를 안 써서 첫 로딩이 1분 넘게 걸림(실제 폰은 훨씬 빠름).
- 확인한 것: 로딩 → 메인 화면(레이더) → 출격 → 걷기·적 처치·스킬 터치, 콘솔 오류 0. 처음 켤 때 Android가 "전체 화면 보기" 안내를 한 번 띄움.

- 저장(진행도·설정)은 WebView의 localStorage에 남는다 — 앱을 지우면 같이 지워짐. 웹 브라우저 저장과는 따로다.
- 화면: 1280×720 판을 기기 화면에 맞춰 줄이고 남는 곳은 검은 띠. 노치(카메라 구멍)가 있는 폰은 그 줄을 비워 둔다(기본 설정).
- 효과음은 `.ogg` — Android WebView는 재생된다. iOS로 갈 때는 `.m4a`/`.mp3`도 필요.
- 디버그 빌드는 `chrome://inspect`로 WebView를 들여다볼 수 있다 (`webContentsDebuggingEnabled`).

## 5. 버전 · 업데이트 (D-074 · NAS D-081)

**흐름**: 앱을 켜면 로딩이 끝난 뒤 **NAS의 `latest.json`**(`app/update.local.json`에 적은 주소)을 읽는다 → 버전이 높거나, 같은 버전에 빌드가 높으면 "UPDATE" 창(바뀐 점) → [업데이트] → 앱 안에서 NAS의 APK를 받고(진행 막대) → Android 설치 화면 → [업데이트]. 설정 창 "정보"에 버전·빌드, [업데이트 확인] 버튼. 인터넷이 없거나 정보가 없으면 조용히 넘어감.
- 처음 한 번은 Android가 "이 출처 허용"(알 수 없는 앱 설치)을 물음 → 켜고 돌아와 [업데이트]를 다시.
- `--required`로 올린 버전은 [나중에] 버튼이 없음.
- 앱 안에서는 Android 코드(`AppUpdatePlugin.fetchText`)가 `latest.json`을 읽는다 → NAS에 CORS 설정이 필요 없다.
- 주소를 넣지 않고 빌드한 앱(`update.local.json` 없음)은 예전처럼 GitHub 최신 릴리스(태그 `vX.Y.Z` + APK)를 읽는다.

**새 버전 올리는 순서** (NAS — 준비는 6장)
1. `js/version_v2.js` — `BUILD`를 1 올림(Android는 이 숫자가 커야 덮어 설치됨). 바뀐 게 크면 `VERSION`도(`0.2.0` → `0.2.1`). Android 쪽 숫자는 `build_www.py`가 자동으로 맞춤.
2. 파일 탐색기에서 NAS 폴더(`update.local.json`의 `nas_dir`)가 열리는지 확인.
3. `app` 폴더에서 `python release.py --notes "바뀐 점" --notes "또 하나"` → 빌드 → `app/dist/MadOverlord-<버전>-b<빌드>.apk` → NAS `releases/<버전>-b<빌드>/`에 복사(옮긴 뒤 SHA-256 대조) → `releases.json`·`latest.json`. 필수 업데이트면 `--required`.
4. 앱을 켠 사람에게 UPDATE 창이 뜸.

| 할 일 | 명령 (`app` 폴더) |
|---|---|
| NAS에 올린 버전 보기 | `python release.py list` |
| 잘못 올린 버전 내리기 | `python release.py latest 0.2.1-b3` (이전 버전을 다시 최신으로) — 아직 안 받은 사람만 해당. 이미 받은 사람은 Android가 낮은 버전으로 못 되돌리므로 **고친 버전을 BUILD를 올려 다시 올린다** |
| NAS가 꺼져 있어 빌드만 됐을 때 | `python release.py upload --notes "…"` (빌드 없이 `app/dist`의 지금 버전을 올림) |
| 빌드만 | `python release.py --no-upload` |

**NAS 폴더 모양** (`release.py`가 만듦 — 손으로 고칠 일 없음)

| 파일 | 내용 |
|---|---|
| `latest.json` | 지금 최신 하나: `version`·`build`·`name`·`notes`·`required`·`file`(APK 상대 주소)·`size`·`sha256`·`date` — 앱이 읽음. 맨 마지막에 바꿔서 올리는 도중에는 예전 것이 보임 |
| `releases.json` | 올린 기록 전부 (새것이 위) |
| `releases/<버전>-b<빌드>/MadOverlord-<버전>-b<빌드>.apk` | APK (예전 것도 남김) |

**서명 키 (꼭 보관)**: 출시용 APK는 `<사용자 폴더>/.android/madoverlord-release.jks`로 서명하고, 비밀번호는 같은 폴더 `madoverlord-release.properties`에 있다(저장소에는 넣지 않음). **업데이트는 같은 키로 서명한 APK만 덮어 설치된다** — 키를 잃으면 모든 사람이 앱을 지우고 다시 깔아야 하므로 두 파일을 안전한 곳에 따로 백업할 것. 다른 PC에서 출시하려면 두 파일을 그 PC의 같은 자리에 둔다.
- 디버그 APK(테스트 키)와 출시용 APK(출시 키)는 서로 덮어 설치되지 않는다 — 디버그판을 깐 사람은 한 번 지우고 출시판을 깐다.
- **NAS판으로 처음 바꿀 때**: 이미 깔린 앱(드라이브의 디버그판, NAS 주소 없이 빌드한 앱)은 NAS를 모른다 → 첫 NAS판 APK는 한 번 직접 받아 설치(NAS의 APK 주소를 알려 주거나 파일 전달). 그다음부터는 앱이 알아서.

**업데이트 시험** (실제 NAS 없이): 설정 파일을 하나 따로 만들어 `{"feed": "http://localhost:8765/madoverlord/latest.json", "nas_dir": "<빈 폴더>/madoverlord"}` → `python release.py --config <그 파일> --notes "시험"` (지금 버전 = A, 에뮬레이터에 설치) → `BUILD`를 올려 한 번 더(B) → PC에서 `python -m http.server 8765 --directory <빈 폴더>` + `adb reverse tcp:8765 tcp:8765` → A를 켜면 B로 UPDATE. 앱은 `localhost`만 http를 허용한다(`res/xml/network_security_config.xml`, 실제 업데이트는 https). 시험 뒤 `version_v2.js`·`build.gradle` 숫자와 `app/dist`를 되돌릴 것. 2026-10-23 에뮬레이터에서 전 과정 확인(D-081): UPDATE 창(빌드 번호·NAS의 바뀐 점) → 내려받기 → "Update this app?" → 0.2.1(빌드 3) → 다시 켜면 창 없음.

## 6. Synology NAS 준비 (처음 한 번 — NAS 관리자)

DSM 7 기준 (메뉴 이름은 DSM 버전에 따라 조금 다를 수 있음). 앱을 **바깥(집·LTE)에서도** 받게 하는 설정이다.

1. **Web Station 설치**: 패키지 센터 → Web Station → 설치. `web` 공유 폴더가 생기고, 이 폴더가 NAS 주소의 웹 페이지가 된다.
2. **폴더 만들기**: `web` 안에 `madoverlord` 폴더. 출시하는 PC에서 쓰는 NAS 계정에 이 폴더 **쓰기 권한**(제어판 → 공유 폴더 → `web` → 편집 → 권한). 바깥 사람은 웹으로 읽기만 한다.
3. **바깥 주소 (DDNS)**: 제어판 → 외부 액세스 → DDNS → 추가 → 서비스 공급자 **Synology** → 호스트 이름 `<원하는 이름>.synology.me` → **"Let's Encrypt에서 인증서 받기"**를 켬. 앱은 **https만** 받는다(자체 서명 인증서·QuickConnect 주소는 안 됨).
4. **공유기 포트 포워딩**: 공유기 관리 화면에서 바깥 **443**(https) → NAS 443. 인증서 받기·갱신에 **80**이 필요할 수 있음. DSM 관리 포트는 열더라도 **5001(https)만** (아래 보안).
5. **확인**: 휴대폰 와이파이를 끄고(LTE) `https://<이름>.synology.me/madoverlord/` 아래 파일이 열리는지 — 첫 출시 전이면 아무 글 파일 하나를 넣어 열어 본다.
6. **출시하는 PC**: 파일 탐색기에서 `\<NAS 이름 또는 IP>\web\madoverlord`가 열리고 파일을 만들 수 있는지 확인 → `app/update.example.json`을 `app/update.local.json`으로 복사해 `feed`(5번 주소 + `/madoverlord/latest.json`)와 `nas_dir`(이 폴더)를 채움. **`update.local.json`은 저장소에 올리지 않는다**(`app/.gitignore` — 공개 저장소라 NAS 주소를 숨김).

- **보안**: `madoverlord` 폴더에는 APK와 JSON만 둔다(폴더 목록 보기는 Web Station 기본값이 꺼짐). DSM 계정은 2단계 인증 권장. 주소를 아는 사람은 누구나 APK를 받을 수 있다 — 더 숨기려면 폴더 이름을 길고 무작위로(`madoverlord-8f3k…`) 하고 `feed`·`nas_dir`도 그 이름으로.
- 바깥 포트를 443이 아닌 번호로 열었으면 `feed`에 포트를 붙인다(`https://<이름>.synology.me:8443/madoverlord/latest.json`).
- **인증서만 남았을 때** (2026-10-23 우리 NAS가 이 상태였음 — DDNS·80·443은 이미 됨, 10-24 해결): 제어판 → 보안 → 인증서 → 추가 → 새 인증서 추가 → **Let's Encrypt에서 인증서 받기** → 도메인 이름 = DDNS 주소 → 완료 → **[설정]에서 "시스템 기본 설정"을 새 인증서로 → [확인]** (DSM 7 목록에는 Web Station 항목이 따로 없다 — 기본 서버(80·443)가 시스템 기본 설정을 따름). 받기만 하고 [설정]을 안 바꾸면 443은 계속 Synology 기본 인증서다. 그 전에는 https가 Synology 기본 인증서라 앱이 업데이트 정보를 못 읽는다(내려받기 페이지는 http로 열림). 인증서를 받으면 앱을 다시 빌드할 필요 없음.
- **DSM 관리 화면은 바깥에 5000(http)으로 열지 않는다** — 로그인 비밀번호가 암호화 없이 오간다. 바깥에서 관리가 필요하면 공유기에서 **5001(https)**만 열거나(시스템 기본 인증서가 DSM에도 붙음), QuickConnect·VPN. 함께: 로그인 포털 "HTTP → HTTPS 자동 리디렉션", 계정 자동 차단, 관리자 2단계 인증.
- 내려받기 페이지: `release.py`가 NAS 폴더에 `index.html`(최신 APK 단추·설치 방법·지난 버전)을 함께 써서, 처음 설치할 사람에게는 폴더 주소(`https://<이름>/madoverlord/`)만 알려 주면 된다.
