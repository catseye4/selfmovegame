# 로드맵

`✅ 완료(게임에서 확인함)` `🔄 진행 중` `⬜ 예정`. 결정의 이유는 [결정기록.md](결정기록.md), 한 일의 자세한 내용은 [작업기록.md](작업기록.md).

## 목표: "완성됐다"의 기준
1. **성장 순환**: 전투에서 DM 획득 → 파츠 구매·강화 → 더 어려운 스테이지. 진행이 저장된다.
2. **스테이지마다 다름**: 적 구성, 배경, 거점, 보스가 달라 반복해도 새롭다.
3. **임시 그림 없음**: CSS 사각형 거점, 색만 바꾼 고블린, 같은 팩션 파츠끼리 똑같은 모습이 없다.
4. **어디서 켜도 잘 돈다**: 창 크기에 맞춰지고, 로딩이 매끄럽고, 적이 많아도 프레임이 유지된다.
