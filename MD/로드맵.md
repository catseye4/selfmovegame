# 로드맵

`✅ 완료(게임에서 확인함)` `🔄 진행 중` `⬜ 예정`. 결정의 이유는 [결정기록.md](결정기록.md), 한 일의 자세한 내용은 [작업기록.md](작업기록.md).

## 목표: "완성됐다"의 기준
1. **성장 순환**: 전투에서 DM 획득 → 파츠 구매·강화 → 더 어려운 스테이지. 진행이 저장된다.
2. **스테이지마다 다름**: 적 구성, 배경, 거점, 보스가 달라 반복해도 새롭다.
3. **임시 그림 없음**: CSS 사각형 거점, 색만 바꾼 고블린, 같은 팩션 파츠끼리 똑같은 모습이 없다.
4. **어디서 켜도 잘 돈다**: 창 크기에 맞춰지고, 로딩이 매끄럽고, 적이 많아도 프레임이 유지된다.

## A. 기반 다지기 (코드만)

| 상태 | 작업 | 완료 기준 |
|---|---|---|
| ⬜ | **저장** | DM, 장착 파츠, 보유 파츠, 파츠 레벨, 스테이지 별을 브라우저에 저장. 새로고침 후에도 그대로 |
| ⬜ | **파츠 소유 + 강화 (D-015)** | 산 파츠는 보유 표시, 다시 끼울 때 무료. 연구소에서 선택 파츠 강화(Lv1~5), 능력치 비교에 반영, 전투 능력치에도 반영 |
| ⬜ | **다리 패시브 3종** | 무한궤도: 진격 중 부딪힌 적에게 돌진 피해 + 밀쳐냄. 반중력 부양: 근접 피해 감소 + 감속 무시. 기본 다리: 이동 속도(능력치). 설명은 v2 표에서 관리(`parts.js`는 수정하지 않음) |
| ⬜ | **화면 크기 맞춤** | 1280x720 화면이 창 크기에 맞게 비율 유지 확대·축소, 가운데 정렬 |
| ⬜ | **로딩 화면** | v2 시작 시 캐릭터 그림·효과음을 미리 받으며 진행 바 표시 후 메인 화면 |
| ⬜ | **자동 검사 정리** | 흩어진 브라우저 검사 스크립트를 `tools/tests/`로 모으고, 한 번에 돌려 통과/실패를 표시 |

## B. 스테이지 뼈대 (코드만, 임시 그림)

| 상태 | 작업 | 완료 기준 |
|---|---|---|
| ⬜ | **스테이지 데이터 (D-018, D-021)** | 챕터 1(구역 1 지하 비밀 연구소) = 1-1~1-5 + 보스전. 거리, 적 구성·능력치, 거점 체력, 보상을 표로 관리. 전투가 이 표를 읽음 |
| ⬜ | **스테이지 선택** | 메인 레이더에 스테이지 점 표시 → 누르면 정보(적, 보상, 별) → 출격. 클리어하면 다음 스테이지 열림 |
| ⬜ | **별 3개 (D-016)** | 요새 / 최종 기지 / 체력 50% 이상. HUD·결과 화면 3칸, 한 번 얻은 별 유지, 새 별 DM 보너스 |
| ⬜ | **적 5종 (D-020)** | 기본 보병, 방패병(피해 감소·넉백 저항), 마취총 사수(원거리, 감속), 전기 충격병(기절), 의무병(치유). 주인공 상태 이상(감속·기절) 표시. 그림은 임시(색조 + 역할 아이콘) |
| ⬜ | **엘리트·보스** | 엘리트(체력↑, 크기·색 변형). 보스전: 거점 광역 포격(EMP 경보 → 기절, 대신 적 보병 전멸 + 잠시 소환 중단, 기획서 2-⑥) + 보스 영웅 |
| ⬜ | **소환 유닛 개선** | 세뇌 보병 = 적 그림 + 보라 세뇌 표식·오라. 합성괴인 졸개 = 합성괴인 리그를 작게 구운 전용 스프라이트 |
| ⬜ | **파츠 외형 차이** | 같은 팩션 파츠(예: 기본 가슴 vs 아다만티움 코어, 레이저 vs 미사일 팔)가 전투·메뉴에서 색으로 구분됨 |
| ⬜ | **밸런스** | 파츠 조합 × 스테이지 자동 전투로 클리어 시간·남은 체력 표를 만들어 난이도 곡선 조정 |
