## 문서 규칙

1. **작업을 마치면** 작업기록.md 맨 위에 항목을 추가한다: 날짜, 한 일, 바뀐 파일, 확인 방법과 결과, 커밋, 남은 일.
2. **무언가를 정하면** 결정기록.md에 `D-번호`로 추가한다. 이미 정한 것을 바꿀 때는 지우지 않고 새 번호를 추가한 뒤, 이전 항목에 `→ D-xx로 대체` 표시를 한다.
3. **기획서와 다른 방향으로 가면** 결정기록에 적고, 기획.MD의 해당 절을 고친 뒤 변경 이력에 한 줄 남긴다.
4. **아직 못 정한 것**은 결정기록의 `확인 필요(Q-번호)`에 둔다. 정해지면 D-번호로 옮긴다.
5. 로드맵의 체크(✅)는 **게임을 실행해 확인까지 끝난 것만** 표시한다.
6. 코드 규칙은 `.agents/AGENTS.md`를 따른다 (구버전 파일은 건드리지 않고 v2만 수정).
