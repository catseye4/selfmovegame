# v2 작업 인계 — `feature/rig-characters-vfx` 브랜치

기존 코드(main)를 알고 있는 작업자에게, 이 브랜치에서 **무엇이 추가되었고 기존 코드의 어디가 바뀌었는지**, **어떻게 받아서 실행하는지** 정리한 문서.
작업 순서별 자세한 기록은 [작업기록.md](작업기록.md), 결정 이유는 [결정기록.md](결정기록.md)(D-번호), 코드 구조는 [기술구조_v2.md](기술구조_v2.md).

## 1. 한눈에 보기

- **브랜치**: `feature/rig-characters-vfx` (main `bc1eabb`에서 갈라짐, **main에는 아직 합치지 않음**)
- **범위**: v2 엔진(디커플드 엔진 모드)만 손봤다. 구버전(오리지널 바닐라 모드)은 그대로 동작한다.
- **결과**: v2가 "움직이는 시안"에서 **한 챕터를 처음부터 끝까지 할 수 있는 게임**이 됐다.
  - 4캐릭터 뼈대 리그 애니메이션과 스킬 이펙트, 게임형 전투 화면과 연출, 효과음·배경음
  - 가로형 메인 화면·연구소, 저장·파츠 구매·강화
  - 챕터 1(5스테이지 + 보스전), 적 5종 + 보스, 제한 시간 규칙과 별 3개
  - 거점·적·배경 그림 (Gemini 이미지 → 자동 가공)
  - 브라우저 자동 검사 110개, 밸런스 자동 측정 도구, 문서 체계(`MD/`)

## 2. 받아서 실행하기

### 받기
**`get_v2_branch.bat`** (main과 이 브랜치 모두 저장소 맨 위에 있음)이 아래 과정을 대신한다 — 브랜치 전환 → 최신 내용 → 원하면 게임 실행.
- **이미 clone해 둔 경우(main)**: `git pull`로 이 파일을 받은 뒤 더블클릭 → v2 브랜치로 바뀐다. main으로 돌아가려면 `git checkout main`.
- **저장소가 없는 경우**: 빈 폴더에 이 파일만 두고 더블클릭 → `selfmovegame\`에 받고 v2로 전환.
- 다시 실행하면 v2 최신 내용으로 업데이트.
변경점을 그림으로 보려면 [v2_변경점.html](v2_변경점.html).

```bash
# 처음 받는 경우
git clone https://github.com/catseye4/selfmovegame.git
cd selfmovegame
git checkout feature/rig-characters-vfx

# 이미 저장소가 있는 경우
git fetch origin
git checkout feature/rig-characters-vfx
git pull
```

### 게임 실행 (Python 3만 있으면 됨)
```bash
python serve.py          # http://localhost:8099
```
1. 크롬에서 **http://localhost:8099** 를 연다.
   - `index.html`을 파일로 바로 열면(`file://`) ES 모듈이 막혀서 동작하지 않는다.
   - `serve.py`는 Windows에서 `.js`가 `text/plain`으로 나가 모듈이 막히는 문제도 막는다.
2. 첫 화면 "엔진 버전 선택"에서 **디커플드 엔진 모드 (v2)** 를 고른다. 오리지널 모드는 예전 그대로다.
3. 메인 화면 → 레이더에서 스테이지 선택 → **출격**.
   - 전투 키: `1` 팔 스킬, `2` 몸통 스킬, `3`/`Space` 필살기, `A` 스킬 자동, `P`/`Esc` 일시정지. 오른쪽 위 `1x`는 2배속.

### 테스트용으로 빨리 보기
- **모든 스테이지 열기 + DM 99999**: 게임 화면에서 F12 → Console에 붙여넣는다.
  ```js
  const s = JSON.parse(localStorage.getItem('mo_v2_save'));
  s.stages = Object.fromEntries(['1-1','1-2','1-3','1-4','1-5'].map(id => [id, { stars: [false,false,false], cleared: true, bestTime: null }]));
  s.dm = 99999; localStorage.setItem('mo_v2_save', JSON.stringify(s)); location.reload();
  ```
- **되돌리기**: 메인 화면 설정(톱니바퀴) → 진행 초기화(두 번 클릭).
- **동작만 크게 보기**: http://localhost:8099/rig_test.html — 주인공 4종 + 적 6종의 대기·걷기·공격.

### 자동 검사·도구 (선택, 개발할 때)
```bash
pip install playwright pillow numpy opencv-python imageio-ffmpeg
python tools/tests/run_all.py          # 브라우저 자동 검사 110개 (설치된 크롬을 화면 없이 사용, 약 3분)
python tools/tests/run_all.py bases    # 이름에 bases가 든 검사만
```
- 검사가 서버를 직접 띄우므로 `serve.py`를 따로 켤 필요 없다. 스크린샷은 `tools/tests/_out/`.
- `opencv-python`·`imageio-ffmpeg`는 그림·소리 가공 도구용이라, 게임 실행과 검사만 할 때는 없어도 된다.

## 3. 기존 코드에서 바뀐 것

### 구버전(오리지널 모드) — 바뀌지 않음
- `js/engine/`, `js/ui/`, `js/main.js`, `index.css`: 변경 없음.
- 두 모드가 같이 쓰는 `js/data/parts.js`(파츠 표)와 `js/engine/state.js`(gameState)도 변경 없음.
  - v2 전용 파츠(괴수 팔 "산성 발톱 팔")는 v2가 시작될 때 `partsExtra_v2.js`가 파츠 표에 추가한다.
  - v2 저장은 `progress_v2.js`가 gameState를 고치지 않고, 시작할 때 값을 채운 뒤 변경을 구독해 저장한다.
- 규칙: `.agents/AGENTS.md` — v2 파일만 수정하고 구버전 파일은 건드리지 않는다.

## 6. 작업할 때 알아 둘 것

- **자동 생성 파일은 손으로 고치지 않는다.**
  - `js/engine_v2/stageArt_v2.js` → `python tools/images/build_bases.py`로 다시 만든다.
  - `js/engine_v2/enemyArt_v2.js` → `python tools/rig/bake_enemies.py`로 다시 만든다.
- **수치를 고치는 곳**:
  - 스테이지(거리·제한 시간·적 구성·거점 체력·보상)는 `stages_v2.js`
  - 적 능력치는 `enemies_v2.js`의 `ENEMY_TYPES`
  - 전투 수치는 `battle/tuning.js` (`OVERLOAD`, `HERO`, `LEG` 등)
  - 스킬은 `skills_v2.js`
- **새 기능에는 검사도 같이 추가**: `tools/tests/test_*.py`, 공용 도구는 `common.py`(`Game.js()`로 페이지 모듈을 직접 조작).
- **문서 규칙**(`MD/README.md`): 작업을 마치면 작업기록, 무언가를 정하면 결정기록, 기획이 바뀌면 기획서와 변경 이력.
- **커밋 메시지**: 한글로 쓴다 (D-032). 2026-09-30 이전 커밋 몇 개는 영문.
