# 협력 출격 — D-085 (2026-10-26 갱신)

> **현재 설정(D-085, 2026-10-26)**: 기본 첫 충전·재충전 **40초**, 출격 **10초**, 궁극기 **2회(0.4·5.4초)**. 계정 연구 「협력 호출 최적화」 3단계는 별 **5·8·10개**로 단계마다 3초 단축하여 **37·34·31초**가 된다. 재충전은 호출 시점부터 계산하며, 전투 시작 시 연구 단계를 복사한다.

사용자 요청: 스테이지 공략 중 **내가 보유한 다른 캐릭터**가 10초 등장해 필살기 2회와 공격으로 지원. 제안한 추가 검토사항까지 포함하여 구현. 컨셉과 현재 동작을 한 번에 보는 문서는 [concepts/협력모드.md](../concepts/협력모드.md).

## 편성과 조작

- 메인 출격 버튼 왼쪽 **협력 출격** 또는 작전 지원 → **협력 출격** 탭.
- D-087: 메인 버튼에 편성한 캐릭터의 얼굴·이름·효과 요약을 표시하고 수동 Q 문구는 제거한다. 편성 자격을 잃으면 효과 대신 재편성 사유를 표시한다. 미선택·후보 있음 상태만 은은하게 강조하고 동작 줄이기 설정에서는 정적인 강조를 유지한다. 편성 창의 선택 카드는 밝은 테두리·배경·**✓ 선택됨** 배지로 구분하고, 다른 캐릭터 선택 시 기존 표시를 해제한다.
- 캐릭터 해금 + 보유 파츠 4부위가 필요. 주인공·파견 중 캐릭터는 제외한다. 부위가 부족하면 이유를 표시한다.
- 직접 1명 선택 또는 **보유 캐릭터 중 랜덤 편성**. 랜덤 결과를 출격 전에 공개하고 저장한다. 전투 때 다시 추첨하지 않는다. 지원 없음도 선택 가능하다.
- 협력 캐릭터를 주인공으로 선택하면 협력 편성·랜덤 표시를 자동 해제하고 메인 버튼을 재편성 안내로 갱신한다(D-086). 예전 중복 저장도 시작 시 정리하고 자동 호출 설정과 다른 유효한 편성은 보존한다.
- 장비·파견 등으로 협력 자격이 바뀌면 화면에서 경고하고, 출격 시 자격을 다시 검사한다. 무효 지원은 투입되지 않으며 스테이지 자체는 출격 가능하다.
- 두 번째 출전 가능 캐릭터가 생기면 메인에 안내. 편성 화면에서 역할·대표 필살기·현재 주인공과의 추천 연계를 설명한다.
- **Q / 지원 초상화**: 첫 호출은 빈 게이지에서 충전 후 가능·무료. 첫 충전과 호출 시점부터 재충전은 각각 기본 **40초(D-085)**. 연구로 최대 31초까지 단축한다. 10초 출격 시간도 충전에 포함하여 철수 직후 남은 재충전은 기본 30초, 연구 최대 시 21초다. 새 스테이지·재시작마다 빈 게이지로 초기화한다.
- 게이지는 최대 1회분만 저장하고 동시 출격은 1명이다. 스킬과 같은 팔각형 초상화 버튼에 충전 부채꼴과 남은 초, 준비 완료 색 효과를 표시한다. 일시정지·히트스톱·배속·슬로모션은 출격과 재충전 모두에 적용한다.
- HUD는 **좌측 상단 주인공 상태창 바로 아래**에 가로형 최소 정보 카드로 배치한다(D-072). 초상화 64px·이름·간략 상태·효과 한 줄·자동 ON/OFF를 상시 표시한다(D-073). 상태는 `첫 충전 / 재충전 / 호출 가능 / 대상 대기 / 지원 중`, 남은 초는 버튼 안에만 표시한다. 접근성 충전 설명에는 남은 초를 유지한다. **효과 상세 ⓘ**를 누르면 같은 상단 자리에서 카드 대신 효과 요약·대표 필살기·전체 효과·보스 예외·10초/40초·연구 규칙을 보여준다. 최대 높이 230px·내부 스크롤로 주인공 전장을 침범하지 않는다. 충전 중에도 열 수 있고, 닫기·바깥 클릭·Escape로 닫는다. 상세가 열린 동안 가려진 카드 조작은 숨기고 닫기로 포커스를 옮긴다. 설명 열기는 호출이나 일시정지를 유발하지 않으며, 닫기/Escape 후 포커스 복귀·기존 일시정지를 보존한다.
- **지원 자동 ON/OFF**는 일반 스킬 AUTO와 독립적이며 저장된다. 보스·엘리트 2명·일반 적 4명·주인공 체력 40% 이하·최종 거점·남은 시간 20초를 보고 호출한다. 성녀는 생존/보스/최종 공략을 우선한다.
- 대상이 없고 보조 효과도 필요 없으면 횟수를 보존한다. 성녀는 부상 상태면 적이 없어도 호출할 수 있다.

## 10초의 규칙

등장 0~0.4초 → 0.4초 첫 궁극기 → 1.9초부터 기본 공격 → 5.4초 두 번째 궁극기 → 6.9초부터 기본 공격 재개 → 9.5~10초 철수. 필살기 지속 효과와 시너지는 철수 전까지 적용된다.

- 게임 시간 기준: 일시정지·히트스톱에 멈추고 배속·슬로모션을 따른다. 2배속 실제 약 5초.
- **근접 공격 팔(`melee`·`scissors`)**은 가까운 적의 아군 쪽, 기본 공격 사거리 안에 즉시 등장한다. 주인공 앞 180px 이동 상한은 근접 지원에 적용하지 않는다. 원거리 공격 팔이면 주인공 주변에서 등장한다. 구분은 캐릭터 이름 대신 출격 스냅샷의 장착 팔 공격 방식과 사거리를 사용한다(D-070).
- 가장 앞의 살아 있는 거점/바리케이드보다 앞쪽으로 소환·이동하지 않는다. 몸의 앞면은 장애물 왼쪽에 둔다.
- 첫 적이 죽으면 가까운 다음 적에게 **출격당 1회, 최대 260px를 0.22초 동안 돌진**한다. 등장 도중 목표가 먼저 죽는 경우도 포함한다. 돌진 중에는 기본 공격을 하지 않는다. 그 밖에는 정상 속도로 이동하며 10초의 출격 시간은 연장하지 않는다.
- 지원 본체는 무적이며 적의 공격 대상으로 등록하지 않는다. 지원이 만든 작은 아군은 기존 미니언처럼 싸우고 피해를 받는다.
- 대표 필살기는 **현재 지원 전용 10개와 신규 캐릭터 공통 지원 공격**. 장착 머리와 같은 기술이라는 의미가 아니며 편성 화면에서 설명한다. 장착 머리별 모든 필살기 지원은 후속 확장.
- 지원 능력치·장비 옵션·장착 머리 스킬 레벨은 출격 시 복사하여 고정한다. 주인공의 공격력·장비 옵션·흡혈을 빌리지 않는다. 대표 필살기의 피해에는 스킬 레벨당 +10% 적용.
- 등장 초상화/텍스트는 짧게 표시하고 전투를 멈추지 않는다. 주인공 필살기와 동시 사용 가능.
- D-076: 적의 제어 상태를 나타내던 `.is-support-held` 네모 테두리만 제거한다. 기존 스킬 VFX·제어/시너지 판정은 유지한다. 추가 아이콘·발밑 오라 등은 스킬 목록 정리 후 각 스킬의 발동/지속 효과 기준으로 검토한다.

## 10종 효과와 캐릭터 추가

목록은 `ROSTER` 전체를 사용한다. `supportUnitOf()`는 별도 협력 정의가 없는 새 캐릭터에도 기본 머리 기술 이름·클립·이펙트를 사용하는 공통 협력 강타를 자동 제공한다. 특화 지원을 원하면 협력 정의 또는 캐릭터의 선택적 `support` 데이터를 더한다. 머리·몸통·팔·다리 소유 여부는 편성과 전투 시작에서 다시 검사한다.

궁극기는 호출 후 0.4초와 5.4초에 발동하며 1.5초 시전 구간에는 일반 공격이 시전 동작을 덮지 않는다. 기술 이름·1/2 또는 2/2 안내·시전자 발동 연출·대상 이펙트를 함께 표시한다. 적 전환 전에도 대상 이펙트를 남겨 세뇌/부활이 생략되어 보이지 않게 한다.

시너지는 지원 출격 중만 유효하다. 추천 조합은 안내이며, 그 밖의 캐릭터도 해당 공격 조건을 만족하면 효과를 받는다. 같은 표식은 중첩하지 않는다.

## 수치와 수명

- 공통 수치는 `js/engine_v2/support_v2.js`의 `SUPPORT`, 캐릭터별 처리 계수는 `battle/support.js`에서 관리한다. 지원 본체의 기본 피해 ×0.55, 기본 공격 0.65초 간격, 필살기 계수 1.6, 직접 공격의 건물 피해 ×0.65.
- 두 번째 궁극기에서도 세뇌 아군 최대 2기·부활 아군 최대 3기를 유지한다. 지원 연출/파생 입자·드론·침묵은 호출 소유자를 구분해 철수 시 제거하고 주인공의 기존 효과는 보존한다.
- 주인공 보호막 = 지원 최대 체력 ×12%, 주인공 최대 체력 ×8%(보스 12%) 중 작은 값. 상한 주인공 최대 체력의 12%. 기존 보호막과 별개로 흡수하며 철수 시 남은 지원 보호막만 지운다.
- 기존 아군 보호막은 아군 최대 체력 비율과 지원 최대 체력 ×4% 중 작은 값.
- 파쇄 추가 피해 = 지원 공격력 ×0.45와 주인공 공격력 ×0.75 중 작은 값. 적당 한 번만 적용하여 다단히트/지속 피해 중첩을 막는다.
- 세뇌/생체 전환에는 처치·드랍 보상을 지급하지 않는다. 실제 지원 공격으로 처치한 적은 기존 경로에서 한 번만 보상한다.
- 지원 소유 `owner`는 **전투 번호 + 호출 순번**으로 매 호출 다르게 부여한다. 예약 작업·드론·미니언·표식·보호막은 철수·퇴각·시간 초과·최종 거점 파괴·보스 승리·재시작 시 정리한다. 이전 출격의 지연 공격은 다음 출격에 영향을 주지 않는다. 피해와 호출 수는 전투 전체에 걸쳐 누적 집계하고 재시작 시 초기화한다. 주인공의 기존 소환수·상태 이상·스킬 버프는 보존한다.

## 일반 공격 표현 (D-085·D-086)

- D-086: 일반 공격의 발사 섬광·타격·광선·미사일·바늘·파동 높이를 기존 대비 1.5배로 표시한다(`SUPPORT.basicFxScale`). 파동은 높이만 조정하고 이동 속도·사거리 배율을 유지한다. 피해량·공격 주기·투사체 도착 시간·궁극기 크기는 유지한다.

- 협력 시전자 리그의 총구/무기 소켓을 전장 좌표로 변환하고 매 일반 공격에 공격 동작·발사 섬광을 재생한다.
- 장착 팔에 따라 근접 타격·레이저/레일/음파 광선·물줄기·미사일·어둠/서리 파동·바늘 투사체를 표시한다. 투사체 공격은 도착 시 적중·피해를 처리하며, 주인공의 전역 스킬/무기를 변경하지 않는다.
- 원거리 지원은 소환 후 실제 사거리까지 접근한다. 이전 주인공 앞 180px 이동 상한으로 먼 적을 끝내 공격하지 못하던 경우를 제거했다. 거점/바리케이드 앞 제한은 유지한다.
- 투사체와 꼬리·파생 입자는 협력 호출 소유자를 이어받는다. 철수/승리 후 과거 적중 콜백은 피해를 주지 않는다.
