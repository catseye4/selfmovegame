# 이미지 제작 가이드 (로드맵 C단계 · Gemini)

챕터 1(구역 1 **지하 비밀 연구소**, D-021)에 필요한 이미지와 Gemini에 보낼 프롬프트.
캐릭터 4종을 만들 때와 같은 방식이다: **컨셉 시트 첨부 → 1단계 기준 이미지 → 같은 대화에서 변형 요청.**
받은 이미지는 채팅에 첨부해 주면 배경 제거·부위 분리·스프라이트 굽기는 코드로 처리한다.

| 우선순위 | 대상 | 장수 | 게임에서 쓰는 곳 |
|---|---|---|---|
| 1 | 거점 2종 × 상태 3개 | 6장 | 중간 요새, 최종 기지 (온전 → 파손 → 붕괴) |
| 2 | 적 5종 + 보스 1 | 종류마다 2~3장 | 스테이지 적 (부위 분리 → 걷기·공격 동작 → 스프라이트로 굽기, D-017) |
| 3 | 구역 1 배경 3층 | 3장 (+ 보스전 변형 1장) | 전투 배경 (먼 배경 / 중간 / 바닥) |
| 선택 | 합성괴인 졸개, 메뉴 격납고 배경 | 2~3장 | 여유가 있을 때 |

---

## 0. 요청할 때 공통 방법

1. **새 대화**를 열고 `MD/캐릭터 컨셉.png`를 첨부한다 (스타일 기준). 적은 크기 비교용으로 우리 캐릭터 그림 하나(예: `assets/sprites/parts/hero/src/hero_neutral_gemini.png`)도 같이 첨부하면 좋다.
2. **[공통 스타일]** 문단 + 대상별 **1단계** 프롬프트를 보낸다.
3. 1단계가 마음에 들면 **같은 대화에서** 2단계, 3단계를 보낸다 ("나머지는 그대로"가 핵심).
4. 자세나 방향 요청이 무시되면: 받은 그림을 다시 첨부하고 "이 그림에서 ○○만 바꿔줘"라고 한 번 더 요청한다. (캐릭터 작업 때도 자세 요청이 자주 무시됐다)
5. 받은 그림은 채팅에 첨부하고 **대상 이름과 단계 번호**만 알려 주면 된다 (예: "방패병 1단계").

### [공통 스타일] — 모든 요청 앞에 붙인다
```text
첨부한 캐릭터 컨셉 시트와 같은 스타일로 그려줘.
- 16비트 풍 도트(픽셀 아트) 게임 그래픽, 어둡고 무거운 SF 분위기
- 굵고 어두운 외곽선, 적은 색 수, 은은한 테두리 빛(림 라이트), 빛은 왼쪽 위에서
- 완전히 옆에서 본 모습(측면 시점)
- 배경은 완전히 평평한 한 가지 색(아래에서 지정한 색)만. 그림자, 바닥, 그라데이션, 배경 소품 없이
- 그릴 대상 하나만, 잘리지 않게 가운데에, 가장자리 여백을 넉넉히
- 글자, 숫자, 로고, 워터마크, 테두리 없이
- 오른쪽 아래 구석은 비워 둬
```

**배경색**: 기본은 `순수 초록색(#00FF00)`. 대상에 초록색이 들어가면(의무병의 초록 십자, 배양액 등) `순수 자홍색(#FF00FF)`으로 바꾼다.

## 1. 거점 건물 (우선순위 1)

게임 크기: 중간 요새 약 90×150px, 최종 기지 약 120×190px. 주인공이 왼쪽에서 다가오므로 **입구·정면이 왼쪽**을 향한다.
세 상태는 **구도·크기·위치가 완전히 같아야** 한다 (게임에서 체력에 따라 그림을 바꿔 끼움).

### 1-A. 중간 요새: 보안 검문소 벙커
**1단계 (온전)**
```text
[공통 스타일]
배경색: 순수 초록색(#00FF00)
세로로 긴 3:4 비율 이미지.

지하 비밀 연구소 안에 있는 "보안 검문소 벙커"를 옆에서 본 모습으로 그려줘. 입구가 화면 왼쪽을 향한다.
- 두꺼운 강철판과 콘크리트로 된 2층 높이의 각진 벙커
- 왼쪽 면에 두꺼운 방폭문, 문 위에 붉은 경고등 두 개
- 지붕 위에 작은 자동 기관포 포탑과 탐조등(포신은 왼쪽을 향함)
- 벽에 노란·검정 경고 줄무늬, 환기구, 케이블, 리벳
- 색: 어두운 회색 강철 + 녹슨 주황 + 노란 경고 줄무늬 + 붉은 경고등
- 건물 아래 가장자리가 이미지 아래쪽 여백 위에 반듯하게 놓이게 (바닥은 그리지 말 것)
```
**2단계 (파손)** — 같은 대화에서
```text
방금 그린 벙커와 구도, 크기, 위치, 시점을 완전히 똑같이 유지하고 "크게 부서진 상태"로만 바꿔줘.
- 강철판이 찢어지고 여러 곳에 구멍, 콘크리트에 금
- 포탑은 기울어지고 포신이 휘어짐, 탐조등 깨짐
- 틈에서 불꽃과 검은 연기가 조금 새어 나옴, 경고등은 하나만 켜짐
- 배경은 똑같이 순수 초록색 한 가지 색
```
**3단계 (붕괴)** — 같은 대화에서
```text
같은 구도, 같은 위치, 같은 아래쪽 기준선으로 "완전히 무너진 잔해 더미"로 바꿔줘.
- 높이는 원래의 1/3 정도, 휘어진 철골과 콘크리트 덩어리가 쌓임
- 잔불과 가는 연기 몇 줄, 부서진 포탑 조각
- 배경은 똑같이 순수 초록색 한 가지 색
```

### 1-B. 최종 기지: 격리 게이트 통제탑
**1단계 (온전)**
```text
[공통 스타일]
배경색: 순수 초록색(#00FF00)
세로로 긴 3:4 비율 이미지.

지하 비밀 연구소의 가장 깊은 곳을 지키는 "격리 게이트 통제탑"을 옆에서 본 모습으로 그려줘. 정면(게이트)이 화면 왼쪽을 향한다.
- 아래쪽: 거대한 원형 격리문(두꺼운 장갑 문, 가운데 잠금 장치)
- 위쪽: 높은 통제탑, 푸른 에너지 코어가 들여다보이는 창, 꼭대기에 레이더 안테나
- 탑 꼭대기 옆에 큰 원통형 "전자기 펄스(EMP) 발사기" 한 대 (광역 포격 무기)
- 배관, 굵은 케이블, 노란·검정 경고 줄무늬, 붉은 경고등
- 색: 짙은 남색 강철 + 푸른 에너지 빛 + 노란 경고 줄무늬
- 탑 아래 가장자리가 이미지 아래쪽 여백 위에 반듯하게 놓이게 (바닥은 그리지 말 것)
```
**2단계 (파손)**, **3단계 (붕괴)**: 1-A의 2·3단계 문장을 그대로 쓰고, "벙커"를 "통제탑"으로, 부서지는 대상을 "격리문 금·EMP 발사기 파손·에너지 코어에서 푸른 불꽃"으로 바꾼다.

## 2. 적 유닛 (우선순위 2)

**설정** (D-020, 컨셉 시트): 적은 오버로드의 탈출을 막는 **연구소 보안대(인간 병사)**. 세뇌되면 컨셉 시트의 검보라 보병이 된다 (세뇌는 코드로 색을 바꾸므로 따로 그리지 않음).
게임 크기는 약 76px로 작다 → **머리가 큰 3등신, 굵은 실루엣, 종류마다 한눈에 구분되는 색**이 중요하다.
모든 적은 **왼쪽을 바라본다** (오른쪽에서 걸어와 왼쪽의 주인공을 공격).

**부위 분리용 자세 (모든 적 공통, 1단계에 넣는다)**
```text
- 완전히 옆에서 본 모습, 화면 왼쪽을 바라봄
- 걷는 중간 자세: 두 다리를 앞뒤로 조금 벌려 서로 겹치지 않게
- 두 팔은 몸통에서 조금 떨어뜨려, 앞팔은 몸 앞쪽·뒷팔은 몸 뒤쪽으로 (팔이 몸통을 가리지 않게)
- 머리, 몸통, 팔, 다리의 경계가 또렷하게
```

### 적 1단계 프롬프트 틀
```text
[공통 스타일]
배경색: 순수 초록색(#00FF00)   ← 의무병만 순수 자홍색(#FF00FF)
정사각형 1:1 이미지.

지하 비밀 연구소를 지키는 보안대 병사 "○○"를 그려줘. (아래 설명)
[부위 분리용 자세]
- 머리가 큰 3등신 비율, 첨부한 캐릭터 옆에 서면 허리 높이 정도의 작은 체구
```
### 적 2단계 (팔 없는 몸) — 같은 대화에서
```text
방금 그린 병사와 몸, 머리, 다리, 자세, 크기, 위치를 완전히 똑같이 두고, 두 팔(과 손에 든 무기)만 지운 그림을 그려줘.
팔이 가리고 있던 몸통 부분은 자연스럽게 채워줘. 배경은 똑같은 한 가지 색.
```
### 적 3단계 (무기 단독) — 무기를 든 적만
```text
방금 병사가 들고 있던 무기(와 무기를 쥔 손)만 따로, 같은 크기와 같은 방향으로 가운데에 그려줘. 배경은 똑같은 한 가지 색.
```
(선택) 뒷다리가 앞다리에 많이 가리면: "앞다리만 지운 그림"을 한 장 더 요청한다.

### 적 설명 (틀의 "○○"와 설명 자리에 넣는다)

| 이름 | 역할 (게임) | 설명 문장 |
|---|---|---|
| **경비병** | 기본 보병, 근접 | `연구소 경비병: 남색 전술복과 방탄조끼, 바이저가 달린 둥근 헬멧, 팔에 노란 경고 줄무늬 완장, 앞손에 짧은 진압봉. 색: 남색 + 회색 + 노란 포인트.` |
| **방패병** | 체력·방어 높음, 밀쳐지지 않음 | `진압 방패병: 두꺼운 중장갑을 입은 덩치 큰 병사, 앞팔로 자기 키만 한 푸른빛 반투명 진압 방패를 앞으로 세워 듦, 뒷손에 곤봉. 색: 짙은 회색 장갑 + 푸른 방패.` |
| **마취총 사수** | 원거리, 맞으면 감속 | `마취총 사수: 가벼운 전술복과 고글, 청록색 약물 캡슐이 꽂힌 긴 마취 소총을 두 손으로 들고 왼쪽을 겨눔, 허리에 캡슐 탄띠. 색: 회색 + 청록 포인트.` |
| **전기 충격병** | 근접, 맞으면 기절 | `전기 충격병: 두꺼운 절연 장갑과 등에 멘 배터리 팩, 앞손에 끝에서 노란 전기가 튀는 전기 충격 창(테이저 창), 헬멧에 번개 표시. 색: 검정 + 노란 전기.` |
| **의무병** | 뒤에서 아군·거점 치유 | `의무병: 흰색·회색 방호복, 헬멧과 어깨에 초록 십자, 등에 치료액 탱크, 앞손에 치료 분사기. 색: 흰색 + 초록 십자.` (배경은 자홍색) |

### 보스: 정의의 수호자 (챕터 1 보스)
타락 히어로가 배신당하기 전 동료였던 **정의의 영웅**. 타락 히어로(검정·보라)와 반대인 **흰색·금색·푸른색**.
```text
[공통 스타일]
배경색: 순수 초록색(#00FF00)
정사각형 1:1 이미지.

연구소를 지키는 영웅 "정의의 수호자"를 그려줘.
- 흰색과 금색의 파워드 슈트, 푸른 에너지 선이 흐름, 뒤로 휘날리는 짧은 푸른 망토
- 앞팔에 육각형 푸른 에너지 방패, 뒷손에 빛나는 금색 장검
- 당당한 영웅 체형 (5등신, 경비병보다 1.5배 큼), 짧은 금발, 결연한 표정
[부위 분리용 자세]
```
2단계(팔 없는 몸), 3단계(방패 단독, 검 단독 — 각각 따로 요청)는 적과 같다.

## 3. 구역 1 배경: 지하 비밀 연구소 (우선순위 3)

전투 화면은 1280×720, 땅은 아래에서 약 60px. 배경은 3층으로 겹치고 층마다 다른 속도로 흐른다.
세 장 모두 **가로로 계속 이어 붙여도 끊기지 않게** 요청한다 (조금 어긋나면 코드로 이음매를 다듬는다).
캐릭터가 잘 보이도록 **어둡고 채도가 낮게**.

### 3-1. 먼 배경 (가장 뒤, 천천히 흐름)
```text
[공통 스타일]에서 "배경은 한 가지 색" 규칙은 빼고, 아래 장면 전체를 그려줘.
가로로 긴 16:9 이미지.

거대한 지하 비밀 연구 시설의 넓은 홀을 멀리서 옆으로 본 풍경.
- 멀리 늘어선 거대한 원통형 배양 탱크(안에 흐릿한 초록·보라 액체와 괴물 실루엣), 천장 크레인, 굵은 배관
- 어두운 천장에 줄지어 켜진 차가운 조명, 바닥 쪽은 옅은 안개
- 어둡고 채도가 낮게, 앞에 설 캐릭터보다 눈에 띄지 않게
- 사람이나 글자는 넣지 말 것
- 왼쪽 끝과 오른쪽 끝이 자연스럽게 이어져 가로로 반복해도 끊기지 않게
```
### 3-2. 중간 층 (벽면, 중간 속도)
```text
[공통 스타일]
배경색: 순수 초록색(#00FF00)
가로로 긴 16:9 이미지.

연구소 복도 벽면을 옆에서 본 모습. 이미지의 아래쪽 55%에만 그리고, 위쪽은 전부 순수 초록색으로 비워 둬.
- 기계 패널, 관찰 창(안쪽이 어둡게 비침), 붉은·노란 경고등, 늘어진 케이블, 닫힌 격벽 문
- 벽 윗선이 들쭉날쭉한 실루엣이 되게 (배관, 환기 장치가 튀어나옴)
- 어둡고 채도가 낮게
- 왼쪽 끝과 오른쪽 끝이 자연스럽게 이어지게
```
### 3-3. 바닥 (맨 앞, 빠르게 흐름)
```text
[공통 스타일]에서 "배경은 한 가지 색" 규칙은 빼고,
가로로 아주 긴 4:1 이미지.

연구소 바닥을 옆에서 약간 위로 본 띠 모양 그림.
- 어두운 금속 격자 바닥, 맨 위 가장자리에 노란·검정 경고 줄무늬 선
- 격자 틈 아래로 희미한 푸른 조명
- 왼쪽 끝과 오른쪽 끝이 자연스럽게 이어져 가로로 반복해도 끊기지 않게
```
### 3-4. (보스전 변형) 경보 조명

## 4. 선택 이미지

### 4-1. 합성괴인 전용 졸개
지금은 합성괴인을 작게 줄인 "미니 괴인"을 쓸 예정(B단계). 따로 디자인하고 싶으면:
```text
[공통 스타일]
배경색: 순수 초록색(#00FF00)
정사각형 1:1 이미지.

첨부한 컨셉 시트의 합성괴인(호랑이+돼지+용 합성 괴물)을 따르는 작은 "졸개 괴물".
- 돼지 코와 호랑이 줄무늬, 작은 뿔, 짧은 박쥐 날개 한 쌍, 조잡한 가죽 갑옷
- 머리가 큰 2.5등신, 합성괴인보다 훨씬 작고 우스꽝스러움
- 화면 오른쪽을 바라봄 (아군이므로)
[부위 분리용 자세] (방향만 오른쪽)
```
### 4-2. 메인 화면 격납고 배경
시안 B v2의 뒤 배경(격납고 내부, 천장 조명, 배관)을 16:9로. 글자·패널 없이 배경만.

## 5. 받은 그림 확인 목록

- [ ] 방향이 맞다 (적·거점은 **왼쪽**, 아군 졸개는 오른쪽)
- [ ] 배경이 **한 가지 색**이고 그림자·바닥·그라데이션이 없다
- [ ] 대상이 잘리지 않았고, 오른쪽 아래 구석(Gemini 로고 자리)에 걸치지 않았다
- [ ] 적: 팔·다리가 몸통을 가리지 않고, 두 다리가 겹치지 않는다
- [ ] 변형 단계: 1단계와 **구도·크기·위치가 같다** (다르면 1단계 그림을 다시 첨부해 재요청)

- [ ] 글자·숫자·로고가 없다
