## 2. 앱 배포 (개발용 NAS)

NAS는 **개발 중 빠르게 확인하는 임시 공간**이다. 운영은 구글 플레이(앱) + 정적 호스팅(웹, Cloudflare Pages 예정)으로 한다.

## 3. 해 볼 때 알아 둘 점 (빌드 9)

- **튜토리얼**: 새로 시작하면 메뉴 아래 진행 줄(1/7)이 보인다. 이미 플레이한 저장에서는 자동으로 안 뜸 → 설정 창 "첫 성장 안내 다시 보기".
- **방치 보상**: 노말 1-1을 깬 뒤, 앱을 10분 넘게 꺼 두면 메뉴 위 단추로 받는다(최대 8시간).
- **펫**: 1-1을 깨면 "회수 드론"이 생김 → 작전 지원 → 펫 탭에서 장착. 그림은 아직 임시 도형.
- **상점**: 상품·가격·확률 정보는 보이지만 결제는 "결제 준비 중". (개발 PC에서 주소에 `?mockCommerce=1`을 붙이면 가짜 결제로 시험 가능 — 시험분은 새로고침하면 사라짐)
- **저장 백업**: 설정 창 → 코드 복사 / 파일로 저장 / 불러오기(웹 ↔ 앱으로 진행 옮기기).
- **시험용 전체 해제**: 메인 메뉴 왼쪽 위 아이콘을 빠르게 5번 → 모든 판·구역이 열림(아이콘이 초록으로 빛남). 다시 켜면 원래대로, 해제로 연 판은 깨도 기록 안 됨. 난이도 잠금은 그대로.
- 수치는 대부분 **1차 임의값**이다(4장).
