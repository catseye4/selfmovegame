## 3. 만드는 방법 — 스킬 공통 부품 (`skillKit_v2.js`)

지금 스킬 51개는 하나하나 코드로 짰다. 192개를 같은 방식으로 짜면 너무 많아 **부품을 조합한 데이터**로 만든다.
스킬 = `{ 이름, 칸, 쿨다운, 아이콘, 색, 동작(리그 클립), 단계[] }`, 단계 = `{ 시점, 부품, 값 }`.

| 부품 | 하는 일 | 쓰는 엔진 기능 (지금 있음) |
|---|---|---|
| `strike` | 대상(가까운·강한·멀리·무작위 N명·사거리 안 전부)을 때림 + 상태 | `dealDamageToEnemy` · `stunEnemy` · `slowEnemy` · `rootEnemy` · `applyBleed` · `applyChill` |
| `line` | 일직선 관통 (광선·찌르기·창) | `enemiesInRange` + 그림 이펙트 |
| `rain` | 넓은 자리에 N번 떨어짐 (유성·용암탄·창·바늘) | `schedule` + 범위 판정 |
| `wave` | 앞으로 움직이는 판정 (파도·돌진 그림자·회전 고리), 되돌아옴 선택 | 새 — 프레임마다 위치 이동, 적마다 한 번/간격 |
| `chain` | 적 사이를 튐 (번개·별빛·실) | 새 — 가까운 다음 적 |
| `zone` | 바닥 장판 (지속 피해·감속·속박 간격·아군 회복) | `addZone` 넓힘 |
| `pull` / `push` | 끌어오기·밀어내기 | `pullEnemy` · `dealDamageToEnemy` knock |
| `dash` / `blink` | 돌진·순간 이동 (지나간 적 피해) | `dashForward` |
| `buff` | 나에게 시간 효과: 피해·받는 피해·이동·공격 속도·쿨다운·회피·치명 | `addBuff` 넓힘 (값을 가진 버프) |
| `shield` · `heal` | 보호막·회복 (나 / 아군) | `applyShield` · 체력 |
| `summon` | 아군 소환 (졸개·인형·늑대·거인 등 그림 + 공격 방식) | `spawnAllyMinion` 넓힘 |
| `screen` | 화면 모든 적에게 (기절·감속·피해·멈춤) | `enemies` |
| `transform` | 커지기 + 공격 바뀜 (마왕 강림 등) | `setGiant` |

- **세트 효과**는 스킬 값을 고치는 꼴로 (예: `{ skill: 'meteorRain', count: +6 }`) → 스킬이 값을 읽을 때 켜진 세트 효과를 더함. 특별한 것만 코드.
- **패시브**도 표로: 조건(멈춤·걷는 중·체력 아래·대상 상태·거리) × 효과(피해·받는 피해·속도·회복·확률 효과).
- **동작(Q7)**: 세트마다 **전용 동작 1~2개** (필살기 위주) + 나머지는 캐릭터 동작 묶음(내려찍기·포효·숨결·찌르기 등)을 씀. 새로 약 70개.
- **이펙트**: 세트마다 **Gemini 그림 시트 1장**(대표 스킬) + 나머지는 지금 시트 32장을 **색 돌리기**(`sprite`에 `hue` 값 새로)로 다시 씀 + 코드 이펙트(장판·고리·줄).

## 4. 그림

- 세트 외형은 **먼저 세트 색**(`SET_TINT`, 지금 A·B 그림 전에 쓰던 방식)으로 구분 → 캐릭터 차례마다 **Gemini 세트 그림**(전신 1장 + 자르기용 1장)을 받아 `cut_<캐릭터>_sets.py`로 잘라 바꿔 끼움.
- 필요한 Gemini 그림 (대략): 세트 그림 64세트 × 1~2 = **약 100장**, 이펙트 시트 2차 48 + 1차 21 = **약 70장** → 두 계정 하루 약 60장 기준 **그림 받는 날만 3~4일** (다시 뽑기는 한 장에 3번까지).
- 12세 기준: 피·상처·십자가 없음, 공포 표현은 "겁먹어 물러남" 수준.
