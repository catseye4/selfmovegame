# 새 스테이지 기획 반영 — 그림·적·판 다시 만들기 계획 (D-085)

기준 기획: [기획_스테이지설계.md](기획_스테이지설계.md) (스테이지 1~10, 2026-10-24 팀원 작성) · 스토리 [기획_캐릭터스토리.md](기획_캐릭터스토리.md) (D-083)

## 1. 사용자 결정 (2026-10-24)

| 물음 | 답 |
|---|---|
| 범위 | **스테이지 1~10 전부 차례로** |
| 적 | **적 구성까지 새 기획대로** — 스테이지마다 적 8종 + 보스, 기술(마비·스킬 지연·장판·자폭·소환 등), 보스전 20초 주기 기믹 |
| 표현 | **기획 표현 그대로** — 지금까지의 12세 순화(D-056·D-058: 피·상처·십자 없음)를 풀고 기획서의 피·고문기구·십자가 표현대로 그림 |
| 판 수 | **기획대로 구역마다 11판** (1~10 + 보스) |

- 기획서의 "스테이지 N" = 게임의 "구역 N". 지금 게임 구역 1~4·6(구역 1 지하 연구소, 2 쓰레기 폐기 정착지, 3 성왕국 수도, 4 진화의 심연, 6 잠긴 병동)은 새 기획으로 바뀜.
- Gemini가 잔혹한 그림을 거절할 수 있음 → 거절되면 그 그림만 표현을 한 단계 누그러뜨린 문장으로 다시 요청(3번까지)하고 기록.

## 2. 순서

1. **배경 40장** — 스테이지마다 4장: 먼 배경(`far`) · 보스전 조명판(`far_boss`, 먼 배경을 첨부해 조명만 바꿈) · 중간 층(`mid`, 단색 배경 = 투명) · 바닥(`floor`, 단색 배경 = 투명). 1 → 10.
2. **거점** — 스테이지마다 중간 요새 3장(온전·파손·붕괴) + 최종 기지 3장 + 장벽 2장 = 8장 (80장).
3. **적** — 스테이지마다 적 8종 + 보스. 적 한 종 = 전신 + 팔 없는 몸 (+ 무기) — 약 22장 (220장).
4. **코드** — 구역마다 적 8종 기술, 보스·20초 기믹, 11판 구성, 거점, 밸런스. 그림이 나오는 대로 구역 단위로.

그림만 약 340장 → Gemini 두 계정 하루 약 90장 기준 4~5일. 한도에 걸리면 코드 작업을 먼저 한다.

**나눠 그리기 (10-25)**: 배경·거점은 **Gemini**, 적·보스는 **GPT(ChatGPT 웹)** 가 동시에 그린다.
- GPT는 투명 배경 PNG(1254×1254)를 바로 줘서 적에 맞음. 스테이지마다 새 대화 하나에서 차례로(화풍·크기 맞춤), 첫 장만 1단계 징집병(`st1/conscript_1_gpt.png`)을 첨부.
- 한 번에 한 장만 요청한다(두 장을 한꺼번에 부탁하면 비슷한 그림 여러 장이 나옴).
- 흰 배경·체크무늬가 그려져 나오면 `gpt_clean.py`로 가장자리에서 이어진 배경색만 투명하게 지운다.

## 3. 파일 자리

- 원본: `assets/sprites/stage/src/st<N>/<층>_gemini.png` (예: `st1/far_gemini.png`)
- 게임용: `tools/images/build_bg.py` LAYERS에 `st<N>/<층>` 추가 → `assets/sprites/stage/st<N>/<층>.webp`
- 요청 글: `tools/images/pending_newplan_bg.json` (그림마다 프롬프트·첨부·배경색)
- 적 원본: `assets/sprites/stage/src/st<N>/<적>_<1|2>_gpt.png` (1 = 전신, 2 = 팔 없는 몸 — 사람형·사람형 보스만). 요청 글: `tools/images/pending_newplan_enemies.json`

## 4. 배경 요청 규칙 (구역 3·4 때 배운 것 그대로)

- 원근·소실점·옆벽 없는 평면(극장 배경막), 좌우가 이어짐, 사람·글자·로고 없음, 어둡고 대비 낮게(앞의 캐릭터가 보이게).
- 첫 장(먼 배경)은 새 대화에 컨셉 시트 첨부. 보스전 판은 새 대화 + 먼 배경 한 장 + "Edit the attached image … same size".
- 중간 층·바닥은 새 대화 + 그 스테이지 먼 배경 첨부("use the same pixel size and colors"), 위·아래는 단색(그림에 없는 색: 초록/분홍/노랑).
- 스테이지마다 분위기 줄을 바꿈: 1 차가운 SF 군사 벙커, 2 산업 재난, 3 고딕 판타지, 4 코스믹 호러, 5 폭풍 해상 요새, 6 타락한 교회 병동, 7 1차 대전풍 전장, 8 극한 설원 왕성, 9 무너진 공사 현장, 10 네온 사이버 방송국.

**10-25 게임 연결 (D-086)**: 배경 40장 `build_bg.py st<N>/` → `assets/sprites/stage/st<N>/{far,far_boss,mid,floor}.webp` (바닥 발 줄은 `NEW_FEET`), 거점 80장 `build_bases.py st` → `st<N>_fort/base/barr` (10단계 요새 레이저 선은 `clip_x0`로 지움, 로고는 `unlogo`),
적 147장 `cut_enemy_parts.py`(GPT 그림은 `key: None`, 팔 차이는 팔 없는 그림에 없는 곳과 이어진 덩어리만, 긴 옷은 `arm_reach`·`not_arm`, 고리 안 흰 배경은 `erase_white`) → `bake_enemies.py`.
구역 1~10 각 11판 = 110판 (`stages_v2.js`), 적 행동·보스·기믹은 `enemies_v2.js`·`battle/enemyField.js`, 검사 `test_stages`·`test_zone2`·`test_zone34`·`test_zone5`·`test_zone6`·`test_zone78`·`test_zone910`.
임의 수치·단순화한 곳은 결정기록 Q-013.

- 적 장수는 사람형이 많으면 늘고(전신+팔 없는 몸), 차량·드론·건물형은 한 장. 6~10단계 적 요청 글은 10-25에 추가(8단계는 열기 주술사가 깨우는 "얼어붙은 병사 조각상" 1장 더, 10단계 7번 철거 용역 깡패는 9단계 그림을 다시 씀).
- 9단계 중간 층이 먼 배경 건물을 그대로 베껴 너무 높게 나와 1번 다시 요청 → 중간 층 규칙에 "62% 위로 아무것도 올리지 말 것, 첨부 그림 건물을 다시 쓰지 말 것"을 더함.
- 10-25 후반에는 Gemini 거점이 끝난 뒤 그 탭에서 ChatGPT 대화를 하나 더 열어 적 두 스테이지를 동시에 받음(8+10, 9 앞·뒤 절반). 9단계 뒷절반 대화는 9단계 깡패(`st9/thug_1_gpt.png`)를 첨부해 화풍을 맞춤.
- 팔 없는 몸이 원본과 달라지면(10단계 집행관 — 갑옷이 날씬하게 바뀜) 전신 `_1`을 첨부해 "Edit the ATTACHED image … do not redesign or slim the body"로 다시. 검은 배경(9단계 다이너마이트 광부 전신)은 원본 첨부 + "only replace the black background with TRANSPARENT".

**자르기 단계에서 고칠 것**
- Gemini "이미지 복사" 그림에도 오른쪽 아래 4각 별 로고가 있음 → 배경·거점 모두 로고 지우기(`unlogo`/inpaint).
- 6단계 요새 1번 오른쪽 아래 작은 아이콘, 10단계 요새의 레이저 선은 자를 때 정리.
- 9단계 톨게이트(거점) 총구가 오른쪽을 봄 → 필요하면 코드에서 좌우 뒤집기. 7단계 기관총 둥지(`mgnest_1`)는 1536×1024.
- 10단계 보스전 조명판(`far_boss`)은 먼 배경과 차이가 약함(분홍 연기·글리치 정도) → 체감 보고 다시 받을지 결정.
- 8단계 블라디미르·9단계 판옵티콘은 그림 가장자리에 거의 닿음(잘린 곳은 없음).
- 9단계 다이너마이트 광부 전신(`dynamite_1`)에 체크무늬가 옅게 몇 줄 남음(다이너마이트·오른쪽 다리 옆).
