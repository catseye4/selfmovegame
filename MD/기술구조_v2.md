# v2 기술 구조

v2(디커플드 엔진)의 코드 지도와 기능을 추가하는 방법. 규칙은 `.agents/AGENTS.md`(구버전 파일 수정 금지, v2만 수정).

## 실행
- 서버: 프로젝트 루트에서 `python serve.py` → `http://localhost:8099/index.html` → **디커플드 엔진 모드 (v2)**
- 캐릭터 리그·이펙트 테스트 화면: `http://localhost:8099/rig_test.html` (전투 없이 동작·이펙트 미리보기, 콘솔 `rigTest.*`)
- 화면: 모두 가로 1280x720 (`.screen-v2.landscape`)

## 구버전과 같이 쓰는 파일 (v2는 읽기만)
- `js/engine/state.js` — `gameState`: DM, 장착 파츠(`equippedParts`), 장바구니(`cartParts`), 능력치 계산, 변경 알림(`subscribe`)
- `js/data/parts.js` — `PARTS_DB`: 부위별 파츠(이름, 팩션, 가격, 능력치, 설명). 설명을 v2 기준으로 바꿀 때는 v2 쪽 표에서 덮어쓴다.

## 기능 추가하는 법

- **스킬**: `skills_v2.js`의 `SKILLS`에 정의 추가(이름, 슬롯, 쿨타임, 아이콘, 색, `use(b)`) → `PART_SKILL`에 파츠 연결. 효과는 전투 엔진의 공용 메서드(`dealDamageToEnemy`, `enemiesInRange`, `fireMissile`, `stunEnemy`, `schedule` 등 — `battle/` 파일들)를 조합.
- **전투 기능**: 성격에 맞는 `battle/` 파일의 메서드 묶음에 추가하면 전투 엔진(`b`)에 붙는다. 매 프레임 할 일이면 `battle_v2.js`의 `loop()` 목록에 한 줄 (순서가 결과에 영향). 이름이 다른 파일과 겹치면 시작할 때 오류. 다른 파일이 부르는 메서드는 `tools/tests/test_battle.py`의 `PUBLIC_API`에 올려 둔다.
- **이펙트**: `vfx/<캐릭터>Vfx.js`에 층 목록으로 정의 → `b.fx.play(정의, x, 바닥높이)`. 효과음은 정의에 `sfx: '이름'`.
- **효과음**: `build_audio.py`의 `SFX`에 원본·가공 방법 추가 후 실행 → `sound_v2.js`의 `SFX` 표에 음량·간격 추가 → `sound.play('이름')`.
- **캐릭터**: Gemini 이미지 → `tools/rig/cut_<이름>_parts.py` → `rig/<이름>Rig.js`(뼈대·클립) → `characters.js` 등록 → `rigAvatar.js`의 팩션 표.
- **거점 그림**: Gemini 그림을 `assets/sprites/stage/src/`에 두고 `python tools/images/build_bases.py` → 크기는 이 파일의 `BASES`.
- **스테이지**: `stages_v2.js`의 `CHAPTER1.stages`에 항목 추가 (적 구성 `mix`는 `enemies_v2.js`의 종류 이름). 레이더 위치는 `map`.
- **적 그림**: Gemini 전신 + 팔 없는 몸(`assets/sprites/stage/src/<적>_1·2_gemini.png`) → `cut_enemy_parts.py`의 `ENEMIES`에 자르는 선 추가 → `python tools/rig/cut_enemy_parts.py <적>` → `enemyRigs.js`에 걷기·공격 → `bake_enemies.py`의 `ENEMIES`에 키·동작 추가 → `python tools/rig/bake_enemies.py <적>`. 근접 공격은 붙어 있는 동안 반복, 한 번 동작은 `enemies_v2.js`의 `playOnce`.
- **적 종류**: `enemies_v2.js`의 `ENEMY_TYPES`에 능력치·색조·능력 정의 → `updateEnemy()`에 행동 추가. 주인공 상태 이상은 `b.applyPlayerSlow/Stun`.
- **파츠 외형 색**: `rigAvatar.js`의 `PART_TINT`(같은 팩션 변형), `SLOT_PARTS`(슬롯 → 리그 부위 그림).
