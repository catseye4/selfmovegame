# [매드 오버로드 (Mad Overlord) 스테이지 1~10 상세 기획 설계서]

---

## 🤖 [스테이지 1] 거대로봇 : 심연의 출격

### ▪ 장소 / 이야기
- **어디인지**: 지하 1,000m에 위치한 제14 비밀 군사 벙커.
- **어떻게 시작하는지 (오프닝)**: 빅터가 다른 세계의 동료들을 부르기 위해 미완성된 '차원문'을 조정하고 있던 찰나, 기술을 탈취하려는 정부의 비밀 토벌군이 기지 문을 폭파하고 들이닥침.
- **무엇을 하는지**: 급히 예열을 마친 기본 프로토타입 거대로봇으로 쏟아지는 토벌군을 무찌르며, 지상으로 통하는 거대한 화물 승강기(최종 거점)를 탈취하기 위해 전진.

### ▪ 색·분위기
- **주색**: 차가운 강철 회색, 비상 경보등의 핏빛 진홍색, 기계 합선의 스파크 푸른색.
- **피할 색**: 자연의 따뜻한 녹색이나 나무 톤(철저히 인공적이고 억압적인 느낌 유지).

### ▪ 막는 세력
- **이름**: 정부 직속 비밀 토벌군 '블랙 하운드'
- **어떤 사람들인지**: 빅터의 기술을 훔쳐 무장한 최정예 진압 부대.

### ▪ 적 8종 (방해 유닛군)
1. **징집 보병 (물량)**: 허름한 방탄복을 입고 소총을 쏘는 기본 병사.
2. **진압 방패병 (바리케이드)**: 묵직한 티타늄 방패를 들고 3열 횡대로 길을 막는 방어 유닛.
3. **테이저 요원 (마비/Stun)**: 전기 올가미를 던져 몬스터의 이동을 2초간 정지시킴.
4. **로켓 보병 (투사체 딜러)**: 후방에서 느리지만 데미지가 큰 대전차 로켓을 곡사로 발사.
5. **EMP 드론 (스킬 지연)**: 공중을 날아다니며 몬스터의 스킬 쿨타임을 늦추는 전파 방해.
6. **전투 군견 (진형 붕괴)**: 이속이 빠르며 다리에 들러붙어 지속 데미지를 줌.
7. **화염방사병 (장판 딜러)**: 바닥에 5초간 꺼지지 않는 네이팜 불길을 깔아 진격 영역 제한.
8. **기계화 강화병 (중간 보스급 탱커)**: 빅터의 기술로 만든 육중한 외골격을 입어 체력이 매우 높음.

### ▪ 보스
- **이름**: WMD-알파 (빅터의 초기 AI 병기)
- **외형**: 빅터가 평화 목적으로 설계했으나, 정부에 의해 흉악한 살상용 인공지능과 장갑이 덧씌워진 거대 이족보행 무인 메카.
- **기술 1 (플라즈마 레이저)**: 에너지를 모은 뒤 전방을 향해 빅터의 기술과 동일한 형태의 강력한 붉은 레이저 빔을 일직선으로 발사.

### ▪ 보스전 기믹
- **기믹 (궤도 폭격)**: 빅터의 스킬을 열화 카피한 시스템. 매 20초마다 천장의 벙커 해치가 열리며 지상에서 호출한 '궤도 폭격'이 바닥의 특정 구역(붉은 원 표시)에 무차별적으로 쏟아짐.

### ▪ 거점
- **중간 요새 = 보안 게이트**: 일정 데미지를 입기 전까지 절대 열리지 않으며, 상단 자동 포탑이 방어 빔을 쏘는 티타늄 격벽.
- **최종 기지 = 지상행 거대 승강기**: 정부군의 물자가 쌓여있는 엄청난 크기의 리프트.

### ▪ 스테이지 구성 (1-1 ~ 1-B)
- **1-1**: 박살 난 연구소 / 오프닝 직후 첫 전투. / 새로 나오는 적: 징집 보병
- **1-2**: 붉은 복도 / 비상등이 깜빡이는 좁은 복도. / 새로 나오는 적: 진압 방패병
- **1-3**: 감전의 위험 / 바닥에 물이 고인 배관 구역. / 새로 나오는 적: 테이저 요원
- **1-4**: 포화 속으로 / 탁 트인 무기고, 후방 지원 사격 시작. / 새로 나오는 적: 로켓 보병
- **1-5**: 첫 번째 차단선 (중간 거점) / 보안 게이트 돌파. / 새로 나오는 적: EMP 드론
- **1-6**: 사냥개 방반 / 좁고 어두운 환풍로 근처. / 새로 나오는 적: 전투 군견
- **1-7**: 불타는 격납고 / 네이팜 화염으로 진격이 까다로워짐. / 새로 나오는 적: 화염방사병
- **1-8**: 도난당한 기술 / 빅터의 기술을 훔쳐 쓴 적들의 등장. / 새로 나오는 적: 기계화 강화병
- **1-9**: 엘리베이터 입구 / 승강기를 타기 위한 총력전. / 새로 나오는 적: (모든 적 혼합)
- **1-10**: 최후의 저지선 / 사방에서 끝없이 쏟아지는 물량 웨이브. / 새로 나오는 적: (모든 적 혼합)
- **1-B**: 통제 불능 / 거대 승강기 앞에서 벌어지는 도용된 AI 병기 'WMD-알파'와의 보스전.

### ▪ 배경 아키텍처
- **먼 배경 (Far)**: 지하 벙커의 끝없는 철골 구조물과 거대한 환풍기 팬.
- **중간 층 (Mid)**: 빅터의 연구 데이터가 불타는 서버랙, 정부군의 수송 차량들, 부서진 벙커 벽면.
- **바닥 (Floor)**: 차가운 강철 그릴(Grill) 바닥, 터진 파이프에서 새어 나오는 증기와 스파크.
- **보스전 조명**: 승강기 구역에 도달하며 천장의 해치가 열리고, 쏟아지는 달빛(또는 햇빛)이 인공지능 보스의 차가운 금속 장갑에 반사되는 연출.

## 🦖 [스테이지 2] 거대괴수 : 끓어오르는 대지

### ▪ 장소 / 이야기
- **어디인지**: 행성의 해안선을 무자비하게 파괴하며 지어진 거대 에너지 코퍼레이션의 '해안 시추 단지'.
- **어떻게 시작하는지 (오프닝)**: 인간들의 해저 핵실험과 무분별한 시추로 해저 지각이 무너지자, 깊은 잠에서 깨어난 태고의 거신(거대괴수)이 화산암과 산호초를 두른 채 끓어오르는 바다를 가르고 상륙.
- **무엇을 하는지**: 행성의 혈관(지맥)을 파먹는 거대 시추 기지의 방어선을 짓밟고, 대자연을 병들게 하는 '메인 시추 코어(최종 거점)'를 완전히 박살 내어 자연의 분노를 각인시킴.

### ▪ 색·분위기
- **주색**: 태고의 용암 적색(Magma Red), 탁한 시멘트 회색(Concrete Grey), 녹슨 철골의 적갈색(Rust Brown).
- **피할 색**: 형광 녹색(단순 오염/방사능 느낌으로 빠지는 것을 방지).

### ▪ 막는 세력
- **이름**: 에너지 코퍼레이션 중장비 방위군
- **어떤 사람들인지**: 괴수의 압도적인 크기에 맞서기 위해, 전투용으로 불법 개조한 산업용 중장비와 로봇을 끌고 나온 용병대.

### ▪ 적 8종 (인간 3종 + 메카/차량 5종)
1. **코퍼레이션 용병 (물량)**: 괴수에게 흠집도 못 내지만 시선을 끌기 위해 소총을 쏘아대는 기본 쫄따구.
2. **불도저 드로이드 (바리케이드/로봇)**: 전방에 거대한 배토판(블레이드)을 달고 진격을 막아서는 무인 궤도 로봇.
3. **고압 작살포 트럭 (슬로우/차량)**: 괴수의 다리에 고장력 강철 케이블이 달린 작살을 박아 넣어 이동을 억제하는 대형 트럭.
4. **벌목용 회전톱 드론 (근거리 딜러/로봇)**: 공중에서 빠르게 날아와 괴수의 외피를 갈아버리려는 거대한 회전톱 비행체.
5. **산성액 투척 메카 (장판/로봇)**: 이족 보행을 하며 산업용 화학 폐기물(산성액) 드럼통을 집어 던져 바닥에 웅덩이를 만드는 로봇.
6. **음파 차단 탑 (스킬 지연/건물형)**: 강렬한 고주파를 쏘아내어 괴수를 괴롭게 만들고 스킬 쿨타임을 늦추는 이동식 음파 발생 장치.
7. **대물 포격 워커 (원거리 딜러/로봇)**: 화면 밖에서 느리지만 육중한 공성용 철갑탄을 쏘아대는 4족 보행 거미형 로봇.
8. **채굴용 엑스카베이터 (중간 보스급 탱커/로봇)**: 거대한 유압식 드릴을 양팔에 장착하고 전면 장갑이 극도로 두꺼운 심층 채굴용 중장갑 로봇.

### ▪ 보스
- **이름**: 기간틱 테라포머 (행성 개척용 초대형 메카)
- **외형**: 원래는 산을 깎고 바다를 메우는 용도였으나, 괴수를 막기 위해 무리하게 무장시킨 압도적 크기의 다관절 중장비 융합 로봇.
- **기술 1 (대지 분쇄 - Pile Bunker)**: 거대한 유압식 강철 기둥(파일벙커)을 바닥에 내리찍어, 괴수가 서 있는 일직선상의 땅을 솟구치게 만드는 물리 충격파 발사.

### ▪ 보스전 기믹
- **기믹 (폐기물 컨테이너 투하)**: 보스전이 진행되는 동안 매 20초마다 천장의 거대 크레인들이 이동하며 쇳물과 폐기물이 가득 찬 '거대 컨테이너 박스' 3개를 무작위 위치(바닥 그림자 경고)에 수직으로 투하함. 맞으면 스턴에 걸리며, 바닥에 떨어진 컨테이너는 잠시 동안 괴수의 길을 막는 바리케이드 역할을 함.

### ▪ 거점
- **중간 요새 = 해안 방파제 게이트**: 거대한 방벽에 대함 미사일 포탑들이 덕지덕지 붙어있는 콘크리트 장벽.
- **최종 기지 = 메인 시추 코어**: 바다 깊은 곳까지 파이프를 박아 넣고 시뻘건 불기둥을 뿜어내는 거대한 시추탑.

### ▪ 스테이지 구성 (2-1 ~ 2-B)
- **2-1**: 대지의 진동 / 상륙 직후. 하찮은 용병들을 짓밟으며 진격. / 새로 나오는 적: 코퍼레이션 용병
- **2-2**: 밀어붙이는 강철 / 불도저 로봇들의 물리적 방어선. / 새로 나오는 적: 불도저 드로이드
- **2-3**: 짐승 사냥 / 괴수의 발을 묶기 시작하는 작살포. / 새로 나오는 적: 고압 작살포 트럭
- **2-4**: 살을 에는 톱니 / 공중에서 쏟아지는 톱날 드론의 위협. / 새로 나오는 적: 벌목용 회전톱 드론
- **2-5**: 방파제 붕괴 (중간 거점) / 대함 포탑이 달린 게이트 돌파. / 새로 나오는 적: 산성액 투척 메카
- **2-6**: 귀를 찢는 기계음 / 음파 공격으로 인한 스킬 사용 방해. / 새로 나오는 적: 음파 차단 탑
- **2-7**: 십자포화 / 원거리에서 쏟아지는 공성탄 폭격. / 새로 나오는 적: 대물 포격 워커
- **2-8**: 뚫리지 않는 껍질 / 양팔에 드릴을 단 중장갑 로봇과의 힘 싸움. / 새로 나오는 적: 채굴용 엑스카베이터
- **2-9**: 시추 코어 진입로 / 메인 기지를 지키기 위한 중장비들의 총공세. / 새로 나오는 적: (모든 적 혼합)
- **2-10**: 최후의 발악 / 사방에서 끝없이 쏟아지는 기계 웨이브. / 새로 나오는 적: (모든 적 혼합)
- **2-B**: 짓밟힌 오만 / 거대 시추탑 앞, 끔찍한 환경 파괴 메카 '기간틱 테라포머'와의 보스전.

### ▪ 배경 아키텍처
- **먼 배경 (Far)**: 시커먼 매연을 뿜어내는 거대한 공장 굴뚝들과 하늘을 뒤덮은 탁한 스모그.
- **중간 층 (Mid)**: 흉측하게 깎여나간 바위산, 늘어선 시추 파이프라인, 그리고 괴수의 발에 밟혀 찌그러진 트럭들.
- **바닥 (Floor)**: 갈라진 아스팔트와 콘크리트 바닥 사이로, 태고의 용암(괴수의 발자국)이 흘러내리며 아스팔트를 녹이는 연출.
- **보스전 조명**: 어두운 매연 속에서 보스가 파일벙커를 내리찍을 때마다 공사장의 '노란색/주황색 경고등'이 번쩍이고, 무너지는 시추탑에서 치솟는 불길이 전장을 붉게 물들임.

## ✝️ [스테이지 3] 타락 히어로 : 피로 물든 순례길

### ▪ 장소 / 이야기
- **어디인지**: 성왕국의 화려한 수도, 그중에서도 이단자들을 처형하던 광장부터 거대한 대성당으로 이어지는 성스러운 순례길.
- **어떻게 시작하는지 (오프닝)**: 피비린내 나는 처형장 한가운데, 억울하게 목이 잘렸던 타락 히어로가 마왕의 권능을 두른 채 망령들을 이끌고 부활하듯 걸어 나옴.
- **무엇을 하는지**: 자신을 배신하고 백성들을 기만하는 성왕국의 군대를 도륙하며, 겉으로만 신성한 척하는 '대성당 정문(최종 거점)'을 박살 내고 위선자 대주교를 처단함.

### ▪ 색·분위기
- **주색**: 빛바랜 황금색(Faded Gold), 처형장의 핏빛(Execution Blood), 마왕의 칠흑(Abyssal Black).
- **피할 색**: 맑고 투명한 하늘색이나 순백색 (신성함이 이미 타락하고 부패했음을 보여주기 위해 칙칙하게 톤 다운).

### ▪ 막는 세력
- **이름**: 성왕국 이단 토벌대 & 광신도 연합
- **어떤 사람들인지**: 겉으로는 여신의 빛을 따르지만, 속은 탐욕과 광기로 썩어빠진 위선적인 맹신도와 부패 기사단.

### ▪ 적 8종 (방해 유닛군)
1. **광신도 무리 (물량)**: 횃불과 쇠스랑을 들고 맹목적인 광기에 차 달려드는 세뇌된 시민들.
2. **신성 방패병 (바리케이드)**: 여신상이 조각된 거대한 황금 방패를 들고 진열을 맞춘 중장갑 보병.
3. **이단심문관 (구속/디버프)**: 가시 박힌 쇠사슬 채찍을 휘둘러 출혈 데미지를 주고 몬스터의 이동 속도를 늦추는 고문관.
4. **빛의 마법사 (투사체 딜러)**: 후방에서 신성한 빛의 화살을 곡사로 쏘아대는 사제.
5. **전투 신관 (힐러)**: 십자가 향로를 흔들어 주변에 있는 적군들의 체력을 지속적으로 회복시키는 까다로운 유닛.
6. **그리폰 기수 (공중/디버퍼)**: 공중을 비행하며 몬스터의 머리 위로 성수를 투척해 일정 시간 방어력을 깎아내리는 기사.
7. **정화의 발리스타 (공성 무기/건물형)**: 먼 거리에서 거대한 은제 쐐기를 발사해 넉백(밀쳐냄)을 유발하는 고정형 포탑.
8. **처형인 성기사 (중간 보스급 탱커)**: 과거 타락 히어로의 목을 직접 쳤던, 거대한 처형용 대검을 든 육중한 정예 기사.

### ▪ 보스
- **이름**: 타락한 대주교 베네딕트
- **외형**: 화려하고 신성한 금빛 교황복을 입고 있으나, 옷자락 끝부분과 눈동자는 마족처럼 검붉게 물들어 있는 끔찍한 위선자. 무기로는 사람 키만 한 강철 십자가를 둔기로 휘두름.
- **기술 1 (신성한 심판 - 빛)**: 하늘에서 3개의 거대한 빛의 기둥을 차례대로 떨어뜨려 몬스터를 쫓아다니며 타격함.
- **기술 2 (숨겨진 마성 - 어둠)**: 교황복 속에서 검은 촉수들을 뻗어내어 전방을 강하게 휩쓸고 자신의 체력을 소량 흡혈함.

### ▪ 보스전 기믹
- **기믹 (위선의 민낯)**: 매 20초마다 대주교가 궁지에 몰려 헛된 기도를 멈추고 지옥문을 개방함. 바닥에 붉은 마법진이 생기며, 대성당 지하에서 은밀히 배양하던 생체 실험의 산물인 '악마 기사(엘리트 몬스터)' 2기를 소환해 자신의 고기 방패로 세움.

### ▪ 거점
- **중간 요새 = 이단 심문소 철문**: 억울하게 죽은 자들의 피가 굳어 있는, 닿으면 반사 데미지를 주는 육중한 가시 철문.
- **최종 기지 = 대성당 정문**: 황금과 스테인드글라스로 사치스럽게 장식된, 가장 화려하지만 썩어빠진 심장부.

### ▪ 스테이지 구성 (3-1 ~ 3-B)
- **3-1**: 처형대의 기억 / 오프닝 직후, 과거 자신이 죽었던 처형장에서 광신도들을 학살. / 새로 나오는 적: 광신도 무리
- **3-2**: 황금빛 방벽 / 성왕국 정규군과의 첫 충돌. / 새로 나오는 적: 신성 방패병
- **3-3**: 피 묻은 채찍 / 순례길을 가로막는 고문관들. / 새로 나오는 적: 이단심문관
- **3-4**: 눈먼 믿음 / 마법사들의 화살비가 쏟아지는 광장. / 새로 나오는 적: 빛의 마법사
- **3-5**: 심문소 돌파 (중간 거점) / 죽지 않는 적들을 치료하는 신관의 등장. / 새로 나오는 적: 전투 신관
- **3-6**: 하늘의 감시자 / 방어력을 깎아내리는 공중 병력의 견제. / 새로 나오는 적: 그리폰 기수
- **3-7**: 이단 정화 포대 / 거대한 은제 쐐기가 날아오는 십자포화 구간. / 새로 나오는 적: 정화의 발리스타
- **3-8**: 원수의 얼굴 / 과거 자신을 죽였던 처형인들과의 피 튀기는 복수전. / 새로 나오는 적: 처형인 성기사
- **3-9**: 대성당의 계단 / 대성당 정문을 지키기 위한 성왕국의 총력전. / 새로 나오는 적: (모든 적 혼합)
- **3-10**: 무너지는 성역 / 사방에서 끝없이 쏟아지는 기사단 웨이브. / 새로 나오는 적: (모든 적 혼합)
- **3-B**: 위선자의 최후 / 대성당 정문 앞, 빛과 어둠을 섞어 쓰는 대주교 베네딕트와의 보스전.

### ▪ 배경 아키텍처
- **먼 배경 (Far)**: 거대하고 화려하지만 어딘가 비틀려 보이는 황금빛 성들과 붉은 노을이 지는 하늘.
- **중간 층 (Mid)**: 억울하게 매달린 화형대, 사치스러운 천사 조각상들, 핏자국이 낭자한 대리석 기둥.
- **바닥 (Floor)**: 하얗게 빛나야 할 대리석 바닥이 망자들의 진격과 피로 인해 시커멓게 짓밟히고 붉게 물듦.
- **보스전 조명**: 성당의 거대한 스테인드글라스를 통해 들어오는 '신성한 황금빛(Gold)'과, 대주교가 마성의 스킬을 쓸 때 바닥에서 솟구치는 '마성의 핏빛(Blood Red)'이 섬뜩하게 교차하며 위선적인 분위기를 극대화함.

## 🧬 [스테이지 4] 합성괴인 : 진화의 심연

### ▪ 장소 / 이야기
- **어디인지**: 우주적 존재들이 생명체의 진화 한계를 실험하기 위해 차원의 틈새에 만든 유기체 실험장 '살점의 요람'.
- **어떻게 시작하는지 (오프닝)**: 끝없는 유전자 조작의 고통 속에서 기적적으로 자아를 각성한 합성괴인이, 자신을 가두고 있던 거대한 고치(수조)를 찢고 쏟아지는 양수와 함께 뚜벅뚜벅 걸어 나옴.
- **무엇을 하는지**: 우주적 존재들의 비틀린 장난감으로 전락한 생명체들을 안식에 들게 하고, 끔찍한 변이 생물들을 뿜어내는 '진화의 고치(최종 거점)'를 파괴하기 위한 핏빛 진격.

### ▪ 색·분위기
- **주색**: 심연의 보라색(Void Purple), 꿈틀거리는 고깃덩어리의 적색(Fleshy Crimson), 기괴한 생체 발광의 형광 녹색(Bioluminescent Green).
- **피할 색**: 기계적인 은색이나 멸균된 하얀색(인공물 느낌을 배제하고 생체적이고 징그러운 느낌 강조).

### ▪ 막는 세력
- **이름**: 별의 사도들과 실패한 진화체들
- **어떤 사람들인지**: 우주적 존재의 속삭임에 미쳐 스스로 육체를 바친 광신도들과, 실험 과정에서 괴물이 되어버린 비극적인 피조물들.

### ▪ 적 8종 (방해 유닛군)
1. **진화의 광신도 (물량)**: 인간의 형상을 잃고 온몸에 핏줄과 종양이 튀어나온 맨몸의 돌연변이들.
2. **생체 방패수 (바리케이드)**: 단단한 갑각과 뼈가 기괴하게 자라나 거대한 뼈 방패를 들고 있는 짐승형 괴물.
3. **심연 촉수귀 (근접 딜러)**: 양팔 대신 기괴하게 꿈틀거리는 거대한 칠흑빛 우주 거머리가 달린 변이체.
4. **키메라 슬라임 (분열 기믹)**: 죽을 때 육체가 터지며 자신보다 작은 2개의 슬라임으로 딱 1회 분열하여 다시 들러붙는 점액질.
5. **포자 술사 (투사체 딜러)**: 등 뒤에서 돋아난 촉수형 식물을 통해 파이어볼처럼 맹독성 우주 포자를 곡사로 발사함.
6. **혈관 기생충 (힐러/버퍼)**: 아군 몬스터의 몸에 들러붙어 체력을 빠르게 회복시키고 이동 속도를 광폭화시키는 징그러운 기생 생물.
7. **안구 감시탑 (원거리/건물형)**: 거대한 눈알이 박혀 있는 박동하는 살점 기둥으로, 일정 주기로 방어력을 관통하는 보랏빛 안광(레이저)을 발사.
8. **광폭화 융합수 (중간 보스급 탱커)**: 수십 마리의 실패작들이 하나로 뭉쳐진 끔찍한 고기 덩어리로, 체력이 매우 높고 죽을 때 산성 혈액을 흩뿌림.

### ▪ 보스
- **이름**: 진화의 관장자 '오큘러스'
- **외형**: 상반신은 거대한 뇌가 노출된 인간형, 하반신은 여러 개의 팔과 다리가 엉킨 거대 우주 벌레의 형상.
- **기술 1 (심연의 파동)**: 바닥에서 뾰족한 가시가 돋친 촉수들을 일직선으로 솟아오르게 하여 띄움(에어본) 피해를 줌.
- **기술 2 (유전자 붕괴 액)**: 끈적이는 우주액을 부채꼴 모양으로 흩뿌려, 맞은 몬스터의 이동 속도와 공격 속도를 대폭 하락시킴.

### ▪ 보스전 기믹
- **기믹 (극한의 변이 - 강제 페이즈 전환)**: 보스의 체력이 50% 이하로 떨어지는 순간 기괴한 비명과 함께 보스의 육체가 강제로 뒤틀림. 양팔이 뼈와 살점으로 엉겨 붙은 거대한 '생체 전기톱'으로 돋아나고, 머리가 터지면서 거대한 '외눈박이(사이클롭스)'로 변모하여 광폭화된 근접 돌진 패턴으로 유저를 압박함.

### ▪ 거점
- **중간 요새 = 박동하는 고기 벽**: 거대한 심장처럼 뛰고 있으며, 다가가면 혈관에서 맹독성 액체를 뿜어내는 살점 바리케이드.
- **최종 기지 = 우주적 고치**: 수만 개의 촉수가 심연의 하늘로 뻗어나가 미지의 존재들과 연결되어 있는 거대하고 불길한 번데기.

### ▪ 스테이지 구성 (4-1 ~ 4-B)
- **4-1**: 찢어진 고치 / 깨어난 직후 달려드는 광신도들을 짓밟으며 탈주 시작. / 새로 나오는 적: 진화의 광신도
- **4-2**: 뼈와 살의 장벽 / 갑각으로 길을 틀어막은 괴물들과의 충돌. / 새로 나오는 적: 생체 방패수
- **4-3**: 변이의 복도 / 거머리 촉수를 휘두르는 짐승들과의 근접 혈투. / 새로 나오는 적: 심연 촉수귀
- **4-4**: 끝없는 증식 / 죽여도 다시 분열하며 들러붙는 점액질들과의 소모전. / 새로 나오는 적: 키메라 슬라임
- **4-5**: 심장벽 돌파 (중간 거점) / 맹독을 뿜는 고기 벽을 분쇄. / 새로 나오는 적: 포자 술사
- **4-6**: 기생의 늪 / 적들을 강화하는 기생충들이 진격을 방해함. / 새로 나오는 적: 혈관 기생충
- **4-7**: 시선이 머무는 곳 / 끔찍한 안구 기둥에서 뿜어지는 레이저 포화. / 새로 나오는 적: 안구 감시탑
- **4-8**: 실패작들의 무덤 / 모든 것이 뒤엉킨 거대한 융합 몬스터의 등장. / 새로 나오는 적: 광폭화 융합수
- **4-9**: 제단의 입구 / 우주적 고치를 지키기 위해 쏟아져 나오는 생물들의 총공세. / 새로 나오는 적: (모든 적 혼합)
- **4-10**: 강요된 진화 / 고치 앞에서 벌어지는 기괴한 살점 웨이브. / 새로 나오는 적: (모든 적 혼합)
- **4-B**: 설계자의 최후 / 관장자 오큘러스와의 보스전. 50% 이하 생체 전기톱 페이즈를 뚫고 고치를 파괴.

### ▪ 배경 아키텍처
- **먼 배경 (Far)**: 별빛이 일렁이는 보라색 심연의 우주, 그 너머에서 이쪽을 지켜보는 듯한 미지 존재들의 흐릿한 눈동자 실루엣.
- **중간 층 (Mid)**: 끝없이 꿈틀거리는 살점 기둥들과 그 안에서 진화를 강요받으며 반인반수로 융합되어 가는 끔찍한 형상들.
- **바닥 (Floor)**: 디딜 때마다 피와 점액이 배어 나오는, 살아 숨 쉬는 유기체 바닥(Flesh Ground).
- **보스전 조명**: 평소에는 스산한 보랏빛이다가, 보스가 50% 이하에서 사이클롭스로 변이하는 순간 거대한 외눈에서 뿜어져 나오는 핏빛 적색(Crimson) 광선이 화면 전체를 붉게 물들이며 광기를 연출함.

## ⚓ [스테이지 5] 심연의 길잡이 : 가라앉는 오만

### ▪ 장소 / 이야기
- **어디인지**: 해양 행성 '어비스'에 남은 단 5%의 육지를 지키기 위해 세워진 무적의 해상 군사 요새 '포세이돈'.
- **어떻게 시작하는지 (오프닝)**: 폭풍우가 몰아치는 바다 밑바닥에서 펄펄 끓는 오염수와 수압을 뚫고, 거대한 잠수복을 입은 길잡이가 해상 요새의 거대한 닻줄을 뜯어내며 묵직하게 갑판 위로 기어 올라옴. 칠흑 같은 심해의 진흙과 부하들의 원혼이 깃든 맹독성 바닷물을 뚝뚝 흘리는 그의 모습에, 과거 그들을 수장시켰던 부패한 해군 병사들이 경악하며 진격이 시작됨.
- **무엇을 하는지**: 자신의 부하들을 맹독성 화산에 수장시킨 부패한 해양 정부를 심판하기 위해, 해상 요새의 철통같은 방어선을 분쇄하고 바다 밑바닥까지 기둥을 박아넣은 '중앙 통제 시추선(최종 거점)'을 파괴하여 남은 육지마저 완전히 가라앉힘.

### ▪ 색·분위기
- **주색**: 칠흑 같은 심해의 흑청색(Abyssal Blue), 부식된 황동과 철골의 녹슨 색(Corroded Brass), 심해 화산의 탁한 주황색(Toxic Magma Orange).
- **피할 색**: 맑고 투명한 에메랄드빛 바다색이나 밝은 열대 수면의 색상(휴양지 느낌 완전 배제).

### ▪ 막는 세력
- **이름**: 어비스 연합 해군 & 특수 잠수 부대
- **어떤 사람들인지**: 오염된 진실을 은폐하고 자신들만의 안전한 육지를 지키기 위해 중무장한 부패 정부의 정규군.

### ▪ 적 8종 (방해 유닛군)
1. **작살총 해병 (물량)**: 방수복을 입고 연발 작살총을 쏘아대는 해상 요새의 기본 경비병.
2. **격벽 방패수 (바리케이드)**: 잠수함의 두꺼운 강철 해치(문)를 뜯어내어 방패로 삼고 전열을 가로막는 중장갑 보병.
3. **그물망 사수 (구속/디버프)**: 고장력 강철 그물을 발사해 몬스터의 이동을 3초간 완전히 묶어버리는 견제 유닛.
4. **수뢰 투척병 (투사체 딜러)**: 바닥에 닿으면 폭발하는 시한성 폭뢰를 포물선으로 던지는 폭파병.
5. **소나(Sonar) 드론 (스킬 지연/드론)**: 공중을 맴돌며 고주파 음파 탐지기를 쏘아 몬스터의 스킬 쿨타임을 마비시키는 무인기.
6. **맹독 잠수부 (자폭/장판)**: 오염 물질에 노출되어 미쳐버린 채, 등에 짊어진 맹독성 산소통을 터뜨려 자폭하며 산성 장판을 남기는 자폭병.
7. **함포 포탑 (공성 무기/건물형)**: 요새 곳곳에 설치되어 무거운 철갑 유탄을 일직선으로 쏘아내는 고정형 방어 포탑.
8. **심해 구축 워커 (중간 보스급 탱커)**: 소형 잠수함을 개조하여 다리를 달아놓은 육중한 이족 보행 메카닉으로 맷집이 매우 높음.

### ▪ 보스
- **이름**: 해군 총사령관 '아이언클래드'
- **외형**: 거대한 핵잠수함의 선체를 통째로 세워 만든 압도적인 크기의 해상 방위용 슈퍼 메카닉에 탑승한 교만한 사령관.
- **기술 1 (심해 압축포)**: 기체의 포문에서 극도로 압축된 고수압의 물기둥을 발사해 강력한 넉백(밀쳐냄)을 유발함.
- **기술 2 (폭뢰 융단폭격)**: 하늘 위로 수십 개의 폭뢰를 쏘아 올려 몬스터가 있는 위치 주변에 무차별적인 연쇄 폭발을 일으킴.

### ▪ 보스전 기믹
- **기믹 (오염된 해저 화산 폭발)**: 매 20초마다 요새 바닥의 철망 아래로 펄펄 끓는 오염된 마그마가 차오르며, 특정 구역의 바닥에서 맹독성 간헐천이 치솟아 올라 지속 데미지를 줌.

### ▪ 거점
- **중간 요새 = 해상 차단 수문**: 접근하면 거대한 전기 충격 작살을 쏘아대는, 요새 구역을 나누는 육중한 강철 수문.
- **최종 기지 = 중앙 통제 시추선**: 바다 깊은 곳의 오염 물질을 퍼 올리며 육지를 유지하는 거대한 원기둥 형태의 메인 코어.

### ▪ 스테이지 구성 (5-1 ~ 5-B)
- **5-1**: 파도치는 갑판 / 해상 요새 상륙 직후 해병들과의 교전. / 새로 나오는 적: 작살총 해병
- **5-2**: 닫힌 해치 / 강철 해치를 들고 길을 막는 방패수들. / 새로 나오는 적: 격벽 방패수
- **5-3**: 옥죄는 그물 / 이동을 묶는 그물망 사수의 등장. / 새로 나오는 적: 그물망 사수
- **5-4**: 쏟아지는 기뢰 / 폭뢰를 던지는 폭파병들과의 난전. / 새로 나오는 적: 수뢰 투척병
- **5-5**: 수문 돌파 (중간 거점) / 전기 작살을 쏘는 수문을 분쇄. / 새로 나오는 적: 함포 포탑
- **5-6**: 찢어지는 이명 / 스킬을 봉쇄하는 소나 드론의 출현. / 새로 나오는 적: 소나(Sonar) 드론
- **5-7**: 끓어오르는 광기 / 맹독을 뒤집어쓴 자폭 잠수부들의 돌진. / 새로 나오는 적: 맹독 잠수부
- **5-8**: 강철의 심해어 / 잠수함을 개조한 중장갑 메카닉과의 힘 싸움. / 새로 나오는 적: 심해 구축 워커
- **5-9**: 폭풍우 속으로 / 시추선을 지키기 위한 해군의 총공세. / 새로 나오는 적: (모든 적 혼합)
- **5-10**: 침몰하는 오만 / 요새의 마지막 방어선에서 벌어지는 대규모 난전. / 새로 나오는 적: (모든 적 혼합)
- **5-B**: 심해의 묘비 / 중앙 통제 시추선 앞, 사령관 아이언클래드와의 보스전. 시추선을 붕괴시켜 요새를 수장시킴.

### ▪ 배경 아키텍처
- **먼 배경 (Far)**: 거센 비바람과 번개가 내리치는 먹구름 낀 하늘, 거친 파도가 부서지는 검은 바다와 멀리 보이는 다른 해상 요새들.
- **중간 층 (Mid)**: 녹슨 크레인, 굵은 쇠사슬, 해군 수송선, 비에 젖은 미사일 발사대.
- **바닥 (Floor)**: 파도가 들이쳐 항상 물이 고여 있는 틈이 벌어진 강철 그릴(Grill) 바닥. 아래로는 출렁이는 검은 바다가 보임.
- **보스전 조명**: 어두운 폭풍우 속에서 요새의 '붉은색 비상 회전등'이 번쩍이고, 기믹 발동 시 바닥 아래에서 뿜어져 나오는 '탁한 주황색(Toxic Magma)' 빛이 길잡이의 실루엣을 기괴하게 비춤.

## 🩸 [스테이지 6] 봉합 성녀 : 피에 젖은 성역

### ▪ 장소 / 이야기
- **어디인지**: 돈과 권력이 있는 귀족들만 치료받을 수 있는 타락한 교회의 최상위 시설, '기적의 대병동'.
- **어떻게 시작하는지 (오프닝)**: 찬란한 스테인드글라스가 산산조각 나며, 거대한 드릴 주사기를 든 성녀가 피투성이가 된 VIP 병동 한가운데로 추락하듯 난입함. 그녀의 뒤로 생명과 기계가 기괴하게 얽힌 '봉합 인형(망자)'들이 쇠사슬을 끌며 기어들어 오고, 돈으로 생명을 사려던 귀족들과 부패한 사제들이 경악하며 물러서는 순간 참혹한 구원의 진격이 시작됨.
- **무엇을 하는지**: 가난한 자들의 피를 뽑아 귀족들의 연명 치료에 쓰는 끔찍한 병동을 짓밟고, 모든 생명을 강제로 연장하는 중앙 코어인 '기적의 성배(최종 거점)'를 파괴하여 교회의 위선적인 생명 통제를 끝냄.

### ▪ 색·분위기
- **주색**: 멸균된 수술실의 창백한 흰색(Sterile White), 말라붙은 핏빛(Dried Blood), 위선적인 교회의 금빛(Hypocritical Gold).
- **피할 색**: 따뜻하고 포근한 파스텔 톤이나 치유를 상징하는 맑은 녹색.

### ▪ 막는 세력
- **이름**: 성혈 의료 기사단
- **어떤 사람들인지**: 치유가 아닌 통제와 고문을 위해 훈련된 교회의 이단 심문관 겸 무장 군의관들.

### ▪ 적 8종 (방해 유닛군)
1. **부패한 간병 보병 (물량)**: 날이 선 거대한 수술용 메스와 뼈톱을 들고 달려드는 하급 사제들.
2. **철의 처녀 방패수 (바리케이드)**: 가시가 박힌 고문기구(아이언 메이든) 뚜껑을 거대한 방패로 삼아 진열을 막는 중장갑 기사.
3. **오염된 성수 투척병 (장판 딜러)**: 바닥에 닿으면 살을 녹이는 유독성 성수 유리병을 던져 지속 데미지 장판을 냄.
4. **마취의(Stun) 주술사 (메즈/마비)**: 원거리에서 수면 가스가 담긴 향로를 흔들어 몬스터의 행동을 2초간 정지시킴.
5. **수혈 팩 드론 (공중/버퍼)**: 공중을 날아다니며 아군 기사들의 체력을 빠르게 회복시키는 비행형 의료 드론.
6. **강제 수혈 실험체 (자폭)**: 빈민들의 몸에 억지로 피와 약물을 주입해 기괴하게 부풀어 오른 괴물. 몬스터에게 닿으면 폭발하며 시야와 이동을 방해함.
7. **기계화 구급 마차 (소환/차량)**: 증기를 뿜으며 달려와 바리케이드 역할을 하는 동시에, 내부에서 하급 사제들을 끊임없이 배출하는 장갑차.
8. **처형의 군의관 (중간 보스급 탱커)**: 거대한 전기톱이 달린 십자가를 휘두르며, 두꺼운 방호복을 입어 체력이 극도로 높은 정예 심문관.

### ▪ 보스
- **이름**: 기적의 성배 : 탐욕의 심장
- **외형**: 귀족들의 영생을 위해 만들어진 흉측한 인공 성배. 수백 개의 수혈관이 핏줄처럼 연결된 거대한 '마름모꼴 핏빛 보석'이 공중에 떠서 실제 심장처럼 기괴하게 박동함.
- **기술 1 (핏빛 파동)**: 보석이 팽창했다가 수축하며, 응축된 피의 충격파를 원형으로 강하게 방출해 몬스터를 뒤로 밀쳐냄(넉백).
- **기술 2 (혈정석 쐐기)**: 허공에 떠 있는 핏빛 보석 표면에서 날카로운 붉은 수정 가시들을 부채꼴 모양으로 넓게 흩뿌려 산탄 발사함.
- **기술 3 (생명력 착취)**: 몬스터 발밑에 거대한 붉은 마법진을 생성하며, 피의 촉수들이 솟아나와 발을 묶고 체력을 지속적으로 빼앗아 심장을 회복시킴.

### ▪ 보스전 기믹
- **기믹 (강제 헌혈)**: 매 20초마다 보스가 강렬한 붉은빛을 뿜어내며 맵 끝에서 3명의 '수혈용 빈민 실험체'를 제단 쪽으로 강제로 끌어당김. 실험체가 심장에 닿아 흡수될 때마다 보스의 체력이 대폭 회복되고 단단한 피의 방어막이 생기므로, 심장에 닿기 전에 실험체들을 빠르게 부숴야 함.

### ▪ 거점
- **중간 요새 = 화형의 소각로**: 시체를 처리하던 거대한 톱니바퀴 문으로, 다가가면 전방으로 강력한 화염 방사기를 뿜어냄.
- **최종 기지 = 성배의 성역**: 귀족들의 연명 치료를 관장하는 지하 제단. 보스인 '탐욕의 심장'을 둘러싸고 있는 거대한 황금 장식물과 유리 수조 자체가 최종 거점의 역할을 함.

### ▪ 스테이지 구성 (6-1 ~ 6-B)
- **6-1**: 깨어진 안식 / 오프닝 직후 VIP 병동을 쑥대밭으로 만듦. / 새로 나오는 적: 부패한 간병 보병
- **6-2**: 닫힌 병실 / 고문 기구로 길을 막는 중장갑 기사들과의 충돌. / 새로 나오는 적: 철의 처녀 방패수
- **6-3**: 독이 든 성수 / 바닥에 깔리는 오염된 장판을 피해 진격. / 새로 나오는 적: 오염된 성수 투척병
- **6-4**: 수면의 향로 / 마취 가스로 진격을 늦추는 주술사 등장. / 새로 나오는 적: 마취의(Stun) 주술사
- **6-5**: 소각로 돌파 (중간 거점) / 불을 뿜는 거대 소각 문을 파괴. / 새로 나오는 적: 수혈 팩 드론
- **6-6**: 터져나가는 희생양 / 빈민 실험체들이 쏟아져 나오는 잔혹한 구역. / 새로 나오는 적: 강제 수혈 실험체
- **6-7**: 죽음의 구급차 / 병력을 계속 뱉어내는 마차를 우선 파괴해야 함. / 새로 나오는 적: 기계화 구급 마차
- **6-8**: 해부학의 달인 / 전기톱 십자가를 든 정예 심문관과의 근접전. / 새로 나오는 적: 처형의 군의관
- **6-9**: 성배를 향하여 / 최종 기지를 지키기 위한 기사단의 총력전. / 새로 나오는 적: (모든 적 혼합)
- **6-10**: 생명의 저울 / 사방에서 끝없이 쏟아지는 의료 기사단 웨이브. / 새로 나오는 적: (모든 적 혼합)
- **6-B**: 무너진 영생 / 수많은 빈민의 피로 박동하는 비인간형 오브젝트 '탐욕의 심장'과의 보스전. 심장을 산산조각 내어 성역을 철거함.

### ▪ 배경 아키텍처
- **먼 배경 (Far)**: 화려한 샹들리에와 웅장한 스테인드글라스, 그 너머로 보이는 잿빛 교회의 첨탑들.
- **중간 층 (Mid)**: 금박으로 장식되었으나 피가 말라붙은 수술대, 구속복이 걸린 철창, 그리고 천장 레일을 따라 이동하는 핏빛 링거병들.
- **바닥 (Floor)**: 본래는 먼지 하나 없이 새하얗던 최고급 대리석 바닥이, 성녀의 진격으로 인해 박살 나고 흥건한 피로 시커멓게 얼룩짐.
- **보스전 조명**: 차갑고 번쩍이는 '수술실 무영등(Clinical White)'의 빛과, 위선적인 성배에서 뿜어져 나오는 쨍한 '황금빛(Gold)'이 소름 끼치는 대비를 이룸.

## 🧵 [스테이지 7] 뒤틀린 인형사 : 잿빛 인형극

### ▪ 장소 / 이야기
- **어디인지**: 끝없는 포격으로 모든 것이 재로 덮인 전쟁터. 그 중심에 있는 처참하게 파괴된 고아원 터.
- **어떻게 시작하는지 (오프닝)**: 폭격으로 박살 난 고아원의 잔해 속, 피 묻은 곰 인형을 안고 고개를 숙이고 있던 인형사. 잔해를 치우고 진격하려는 제국군 보병들이 다가오자, 그의 등 뒤에서 기괴한 태엽 소리와 함께 흉측한 인형들이 쏟아져 나오며 핏빛 인형극의 막이 오름.
- **무엇을 하는지**: 아이들을 앗아간 포탄을 쏜 제국군의 참호 방어선을 갈아버리고, 전쟁을 지휘하는 '전방 사령탑(최종 거점)'을 무너뜨려 이 참혹한 전장에 영원한 침묵을 선사함.

### ▪ 색·분위기
- **주색**: 끝없는 매연의 잿빛(Ash Grey), 차가운 총열의 철색(Gunmetal), 흐릿하고 병든 화염의 누런색(Sickly Yellow).
- **피할 색**: 희망을 상징하는 밝은 파란색이나 선명한 빨간색(철저하게 채도가 낮고 절망적인 색감 유지).

### ▪ 막는 세력
- **이름**: 제국 제1 포병 사단
- **어떤 사람들인지**: 오직 승리와 영토 확장에 눈이 멀어 민간인 구역(고아원)마저 무차별 포격한 피도 눈물도 없는 잿빛 군대.

### ▪ 적 8종 (방해 유닛군)
1. **참호 징집병 (물량)**: 진흙과 핏자국이 묻은 군복을 입고 총검을 든 채 돌격하는 기본 보병.
2. **철조망 방패병 (바리케이드)**: 가시 철조망이 잔뜩 감긴 거대한 바리케이드를 통째로 들고 막아서는 방어 유닛.
3. **유산탄 투척병 (장판 딜러)**: 터지면 날카로운 파편이 사방으로 튀는 수류탄을 던져 광역 피해를 주는 척탄병.
4. **독가스 살포병 (디버퍼)**: 방독면을 쓰고 전방에 노란색 겨자 가스를 살포해, 몬스터의 이동 속도와 공격력을 깎아내림.
5. **돌격 장교 (버퍼/소환)**: 호루라기를 불어 주변 제국군의 이동 속도와 공격 속도를 미친 듯이 상승시키며, 동시에 참호 속에서 제국군 보병 3~5명(랜덤)을 즉시 소환하여 라인을 압박하는 악랄한 지휘관.
6. **지뢰 매설병 (함정)**: 몬스터가 다가가면 은신 상태에서 튀어나와 밟으면 스턴에 걸리는 대전차 지뢰를 깔고 도망감.
7. **야전 기관총 좌 (원거리/건물형)**: 참호 속에 설치되어 끝없이 총알을 쏟아내는 고정형 토치카.
8. **증기기관 전차 (중간 보스급 탱커)**: 시커먼 매연을 뿜으며 굴러오는 낡았지만 무식하게 튼튼한 제국군 초기형 전차.

### ▪ 보스
- **이름**: 심판의 구포(Mortar) : 베헤모스
- **외형**: 고아원을 날려버렸던 바로 그 거대한 대량 살상용 곡사포. 기차 선로 위를 다족 보행으로 기어 다니도록 마개조된 흉측하고 거대한 거북이 형태의 공성 메카닉.
- **기술 1 (철갑탄 직사)**: 거대한 포신을 아래로 내려 정면을 향해 포탄을 발사하여 관통 데미지와 넉백을 줌.
- **기술 2 (백린 소이탄)**: 포탄이 공중에서 터지며, 바닥에 닿으면 꺼지지 않고 뼈까지 태우는 하얀 불길(지속 데미지 장판)을 넓게 깔음.
- **기술 3 (궤도 톱니 돌진)**: 육중한 몸체를 지탱하는 무한궤도의 톱니바퀴를 고속 회전시키며 전방으로 무자비하게 밀고 들어오는 물리 충돌 패턴.

### ▪ 보스전 기믹
- **기믹 (사각지대 없는 포격 - 자동전투형 DPS 체크)**: 매 20초마다 보스가 하늘로 붉은 조명탄을 쏘아 올립니다. 조명탄이 떠 있는 동안 맵 전체에 무차별적인 융단 폭격 경고(수많은 붉은 원)가 나타나며, 조명탄 오브젝트를 재빨리 부수지 않으면 맵 전체에 즉사급 포격이 쏟아집니다.

### ▪ 거점
- **중간 요새 = 강철 참호 벙커**: 대전차포와 기관총이 빼곡하게 튀어나와 진격을 거부하는 육중한 콘크리트 벙커.
- **최종 기지 = 제국군 전방 사령탑**: 잿빛 하늘 높이 솟아올라 전쟁을 지휘하는, 수많은 안테나와 스피커가 달린 거대한 통제탑.

### ▪ 스테이지 구성 (7-1 ~ 7-B)
- **7-1**: 부서진 요람 / 고아원 터. 태엽 인형들과 참호 보병들의 첫 충돌. / 새로 나오는 적: 참호 징집병
- **7-2**: 찢어진 곰 인형 / 철조망을 찢으며 참호선으로 진입. / 새로 나오는 적: 철조망 방패병
- **7-3**: 비명과 파편 / 파편 수류탄이 빗발치는 전장. / 새로 나오는 적: 유산탄 투척병
- **7-4**: 노란 안개 / 시야를 가리는 독가스 지대 돌파. / 새로 나오는 적: 독가스 살포병
- **7-5**: 벙커 분쇄 (중간 거점) / 쏟아지는 기관총을 뚫고 콘크리트 벙커 파괴. / 새로 나오는 적: 야전 기관총 좌
- **7-6**: 죽음의 호루라기 / 적군을 쏟아내는 돌격 장교 출현. / 새로 나오는 적: 돌격 장교
- **7-7**: 보이지 않는 덫 / 바닥에 깔리는 대전차 지뢰밭. / 새로 나오는 적: 지뢰 매설병
- **7-8**: 쇳덩어리의 돌진 / 매연을 뿜는 전차와의 힘 싸움. / 새로 나오는 적: 증기기관 전차
- **7-9**: 사령탑 진입로 / 지휘부를 방어하려는 제국군의 총력전. / 새로 나오는 적: (모든 적 혼합)
- **7-10**: 재와 먼지 / 잿빛 폭풍 속에서 끝없이 쏟아지는 방어 웨이브. / 새로 나오는 적: (모든 적 혼합)
- **7-B**: 끊어지지 않는 실 / 전방 사령탑 앞, 고아원을 부순 장본인인 다족보행 공성포 '베헤모스'와의 보스전.

### ▪ 배경 아키텍처
- **먼 배경 (Far)**: 시커먼 연기가 솟아오르는 파괴된 도시의 실루엣, 쉴 새 없이 번쩍이는 포격의 섬광과 비행선들.
- **중간 층 (Mid)**: 뼈대만 남은 벽돌 건물들, 파괴된 전차의 잔해, 겹겹이 쳐진 철조망과 참호선.
- **바닥 (Floor)**: 포탄 구덩이로 푹 파인 진흙탕 바닥. 곳곳에 부러진 총검과 버려진 탄피, 불타다 만 나무 인형 조각들.
- **보스전 조명**: 빛이 들지 않는 탁한 잿빛 하늘에서 보스가 쏘아 올린 '조명탄의 핏빛 붉은 조명'만이 전장을 섬뜩하게 밝히며 인형사의 거대한 가위 실루엣을 비춤.

## ❄️ [스테이지 8] 서리의 무희 : 얼어붙은 안식

### ▪ 장소 / 이야기
- **어디인지**: 일 년 내내 눈보라가 치는 영구동토의 왕국 '노르딘'. 백성들을 착취해 거대한 화로석들을 독점한 왕성 내부.
- **어떻게 시작하는지 (오프닝)**: 극단원들과 마을 사람들이 서로를 껴안은 채 꽁꽁 얼어붙어 있는 처참한 빙상 공원. 슬픔에 잠겨 무릎을 꿇고 있던 무희가 천천히 일어나는 순간, 대기가 급속도로 얼어붙으며 성왕국 경비대들의 무기가 서리에 박살 나고 죽음의 춤이 시작됨.
- **무엇을 하는지**: 온기를 독점하고 백성들을 얼려 죽인 오만한 국왕의 방어선을 눈보라로 갈아버리고, 왕성의 모든 에너지를 공급하는 '메인 화로석 제단(최종 거점)'을 박살 내어 세상을 영원한 고요에 빠뜨림.

### ▪ 색·분위기
- **주색**: 영구동토의 창백한 푸른색(Frost Blue), 화로석의 인공적이고 탐욕스러운 붉은색(Furnace Red), 흩날리는 백색 눈보라.
- **피할 색**: 자연스럽고 따뜻한 햇살의 색.

### ▪ 막는 세력
- **이름**: 노르딘 왕실 근위대 & 온기 탐식자들
- **어떤 사람들인지**: 무희의 치명적인 서리에 맞서기 위해 화로석의 열기를 훔쳐 무기에 바르고 불꽃을 다루는 이기적인 친위 병력.

### ▪ 적 8종 (방해 유닛군)
1. **횃불 징집병 (물량)**: 얼어붙지 않기 위해 거대한 횃불을 휘두르며 필사적으로 달려드는 병사.
2. **화로 방패병 (바리케이드)**: 불타는 소형 화로석이 박힌 강철 방패를 들어, 공격하는 몬스터에게 근접 화상 피해(반사 데미지)를 입히는 방어 유닛.
3. **끓는 기름 투척병 (장판 딜러)**: 바닥에 닿으면 눈을 녹이고 끓어오르는 기름병을 던져 지속 화상 피해를 주는 척탄병.
4. **작살총 사냥꾼 (구속)**: 눈보라 속에서 이동 속도를 늦추는 거대한 덫과 강철 그물을 발사하는 사수.
5. **열기 주술사 (소환/타이머 기믹)**: 등장 시 얼어붙은 병사 조각상(랜덤 적 유닛) 3~5기와 함께 출현. 일정 시간이 지나 주술사가 스킬을 발동하면 조각상들이 순식간에 녹아내리며 즉시 적 유닛으로 활성화되어 라인에 쏟아짐.
6. **증기 돌파병 (자폭)**: 몸에 고압 증기통을 매달고 돌진하여 자폭, 몬스터의 시야를 가리는 뜨거운 수증기(명중률 하락)를 방출함.
7. **열광선 포탑 (건물형/디버퍼)**: 붉은 열광선을 뿜어내어 무희의 서리 마법(스킬)을 빠르게 융해시켜 데미지를 반감시키는 고정형 난로.
8. **화염 늑대 기사 (중간 보스급 탱커)**: 화염 갑옷을 두르고, 털에 불이 붙은 거대한 짐승(거대 서리늑대)을 탄 정예 기사.

### ▪ 보스
- **이름**: 탐욕의 폭군 '블라디미르' 국왕
- **외형**: 전설 속 화룡의 비늘과 뼈, 그리고 화로석의 코어를 융합하여 벼려낸 기괴하고 육중한 '화룡의 갑옷'을 입고 펄펄 끓는 거대한 화염 대검을 든 오만한 늙은 왕.
- **기술 1 (화룡의 숨결)**: 대검을 크게 휘둘러 전방 일직선으로 거대한 화염 브레스(검기)를 방출해 넓은 범위를 불태움.
- **기술 2 (잿더미 유성우)**: 대검을 하늘로 치켜들어 불타는 화산암을 쏟아지게 하여 맵 곳곳에 지속 화염 장판을 생성.
- **기술 3 (온기 강탈)**: 맵 전체의 열기를 갑옷의 코어로 강제 흡수하여 유저 몬스터를 일시적으로 빙결(스턴) 상태로 만들고, 자신의 화염 보호막을 대폭 충전함.

### ▪ 보스전 기믹
- **기믹 (탐욕의 제단 - 자동 전투형 DPS 체크)**: 매 20초마다 블라디미르 국왕이 전방에 3개의 '압축된 화로석 제단(오브젝트)'을 강제로 소환하여 길을 막습니다. 제단이 유지되는 동안 맵 전체에 치명적인 '열파동(지속 화상 데미지)'이 들어오고 국왕의 공격력이 상승합니다. 우리 몬스터들이 이 제단을 자동으로 타격하며, 파티가 전멸하기 전에 화력을 집중해 3개의 제단을 모두 부수면 기믹이 파훼되고 국왕이 스턴에 빠집니다.

### ▪ 거점
- **중간 요새 = 펄펄 끓는 용광로 성문**: 다가가면 위성 궤도 포격처럼 바닥에서 거대한 불기둥을 솟구치게 하는 굳게 닫힌 거대 강철문.

### ▪ 색·분위기
- **주색**: 공사장의 경고등인 안전제일 노란색(Hazard Yellow), 탁한 시멘트 회색(Concrete Grey), [10스테이지와 공유] 멀리서 비추는 네온 핑크(Neon Magenta).

2. **콘크리트 방패 드론 (바리케이드)**: 굳어버린 두꺼운 시멘트판을 앞세워 길을 막는 궤도형 로봇.
3. **시멘트 살수병 (슬로우/장판)**: 닿으면 굳어버리는 속효성 시멘트를 바닥에 뿌려 몬스터의 이동 속도를 크게 늦춤.

8. **레킹볼(Wrecking Ball) 크레인 (중간 보스급 탱커)**: 거대한 철구를 앞뒤로 흔들며 다가오는 무식하게 튼튼한 중장비 차량.

## 📻 [스테이지 10] 침묵의 방송자 : 거짓된 주파수

### ▪ 장소 / 이야기

### ▪ 색·분위기
- **주색**: 사이버펑크의 강렬한 네온 핑크(Neon Magenta), [9스테이지와 공유] 탁한 시멘트 회색(Concrete Grey), 빛을 흡수하는 칠흑(Obsidian Black).

- **어떤 사람들인지**: 기업의 개가 되어 진실을 탄압하는 경찰 병력과, 전파에 세뇌되어 자아를 잃은 시민들.

2. **음파 방패 경비대 (바리케이드)**: 핑크빛 소음 장막(에너지 실드)을 방패처럼 전개하여 전열을 막는 진압 경찰.
3. **스피커 드론 (디버퍼)**: 공중에서 끔찍한 소음을 방송하여 아군 몬스터의 공격력을 감소시킴.

6. **우퍼(Subwoofer) 메카 (넉백/차량)**: 전면에 거대한 스피커를 단 장갑차가 음파를 쏘아 아군을 뒤로 밀어냄.

8. **통제국 집행관 (중간 보스급 탱커)**: 온몸을 사이보그로 개조하고 전기 진압봉을 휘두르는 체력 뻥튀기 정예 경찰.

- **기술 3 (통제 레이저)**: 심장 정면의 거대한 렌즈에서 맵 전체를 꿰뚫는 강력한 일직선 궤도 레이저 발사.

- **기믹 (세뇌 방송국 가동 - 자동 전투형 DPS 체크)**: 매 20초마다 보스가 무적 상태가 되며, 보스를 둘러싼 4개의 '세뇌 증폭 안테나(오브젝트)'가 바닥에서 솟아납니다. 이 안테나 4개를 빠르게 점사하여 파괴하지 않으면, 10초 뒤 안테나들이 공명하며 즉사급의 '소음 파동'을 발사합니다.

### ▪ 거점
- **중간 요새 = 전파 차단 격벽**: 무수한 레이저 감지기가 달린 방송국의 메인 보안문.
- **최종 기지 = 타워 최상층 코어 룸**: 도시 전체에 방송을 내보내는 '마더 보이스'가 위치한 중앙 통제실.

### ▪ 스테이지 구성 (10-1 ~ 10-B)
- **10-1**: 거짓의 도시 / 방송국 진입 직후 세뇌된 폭도들과의 전투. / 새로 나오는 적: 세뇌된 시민
- **10-2**: 소음 장막 / 음파 실드를 전개하는 경찰 병력. / 새로 나오는 적: 음파 방패 경비대
- **10-3**: 귀를 찢는 방송 / 공중에서 공격력을 깎는 스피커 드론의 견제. / 새로 나오는 적: 스피커 드론
- **10-4**: 네온 십자포화 / 핑크빛 레이저 저격 구간. / 새로 나오는 적: 광선 저격 경찰
- **10-5**: 보안문 돌파 (중간 거점) / 레이저 감지 격벽을 무너뜨리고 내부 진입. / 새로 나오는 적: 주파수 교란기
- **10-6**: 끊어진 전파 / 스킬을 봉쇄하는 안테나 무력화 작전. / 새로 나오는 적: 우퍼(Subwoofer) 메카
- **10-7**: 진동하는 대지 / 밀쳐내는 우퍼 메카와의 전열 싸움. / 새로 나오는 적: 철거 용역 깡패 (9스테이지 혼합)
- **10-8**: 강제 진압 / 전기봉을 든 정예 사이보그 경찰과의 충돌. / 새로 나오는 적: 통제국 집행관
- **10-9**: 코어 룸 입구 / 최상층을 지키기 위한 방송국 병력의 총력전. / 새로 나오는 적: (모든 적 혼합)
- **10-10**: 영원한 침묵을 위하여 / 끝없이 몰려오는 사이버펑크 웨이브. / 새로 나오는 적: (모든 적 혼합)
- **10-B**: 빼앗긴 목소리 / 메인 기계 코어 '마더 보이스'와의 최종 보스전.

### ▪ 배경 아키텍처
- **먼 배경 (Far)**: [세계관 연계] 타워 최상층에서 내려다보는 풍경. 저 멀리 '9스테이지에서 설계자가 무너뜨려 흙먼지가 피어오르는 거대 건설 구역'의 붕괴 잔해가 흐릿하게 보임.
- **중간 층 (Mid)**: 쉴 새 없이 돌아가는 네온 전광판과 홀로그램 기업 광고들, 수많은 케이블 선.
- **바닥 (Floor)**: 매끄럽고 차가운 검은색 하이그로시 바닥에 핑크빛 네온이 반사됨. 진격에 의해 바닥이 깨지며 내부의 스파크가 튐.
