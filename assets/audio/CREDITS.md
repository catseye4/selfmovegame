# 사운드 출처 (모두 CC0 — 저작자 표시 의무 없음, 감사의 뜻으로 기록)

게임용 파일은 `tools/audio/build_audio.py`로 원본을 다듬어(자르기, 음높이, 겹치기, 음량 맞춤) 만든다.
사이렌(`warning`, `warning_danger`), 심장 박동(`low_hp`), 휙 소리(`intro_whoosh`), 필살기 상승음(`ult_cutin` 앞부분)은 코드로 합성했다.
